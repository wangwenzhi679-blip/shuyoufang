# 数有方 · 研习空间

数有方是面向个人自主学习的课程学习平台。以导入资料为起点，将课程、章节阅读、AI 问答、笔记、练习、错题复习和学习计划串联起来。界面采用纸色、墨色与少量朱红、青绿，保持统一的中式研习风格。

本项目包含用户端、管理端和后端服务，学习数据主要存储在 MySQL 与后端文件目录中。

## 在线访问

| 服务   | 地址                            | 说明                     |
| ------ | ------------------------------- | ------------------------ |
| 用户端 | <https://shuyoufang.asia/>      | 学习首页、课程与学习工具 |
| 管理端 | <https://shuyoufang.asia/admin> | 需要管理员账号登录       |

网站已部署到云服务器，直接通过以上地址访问，无需在自己的电脑启动前端、后端或数据库。

下方安装与环境配置用于本地开发或自行部署，不是在线访问的前置步骤。

## 已有功能

### 用户端

- **学习首页**：继续学习、今日任务、最近学习、学习记录与连续学习情况。
- **我的课程**：导入资料创建课程，管理章节、资料、课程封面和章节配图。
- **章节学习**：阅读章节内容与原资料，修正章节文字，生成章节总结，记录阅读进度与书签。
- **学习助手**：选择课程或章节范围进行问答，管理研习对话，将回答加入笔记。
- **笔记与练习**：编辑学习笔记，生成和完成章节练习，查看答题记录。
- **错题复习**：管理错题、掌握状态与复习安排。
- **学习计划**：制定学习计划，调整任务与日期，记录任务进度。
- **账号与设置**：修改个人资料、调整字体与模型偏好、管理配图、切换账号及退出登录。

AI 整理、问答和生图需要相应服务可用。普通课程管理与已有学习内容不依赖每次调用 AI。

### 管理端

- **管理首页**：查看用户、课程、资料和生成任务概况，核查存储状态。
- **用户管理**：查询用户、查看学习数据统计，停用、恢复或注销学习账号。
- **课程与资料查询**：筛选和查看详情，暂停或恢复内容，修复资料预览。
- **AI 任务**：查看生成任务、诊断信息，按任务状态执行取消或重试。
- **公告管理**：编辑和发布平台公告。
- **服务状态**：配置文字 AI、邮件及章节配图服务，检查连接与查看检查结果。
- **运行设置与备份**：管理运行限制，创建、验证、下载及删除历史备份。
- **操作日志**：检索管理操作及处理结果。

停用可以恢复；注销不可恢复，会撤销登录权限并解绑邮箱。注销后账号名称和学习记录仍保留供管理核查，并非清空该用户的全部数据。管理员账号不能通过用户管理中的注销功能处理。

## 云服务器安装与配置

已有可用环境不需要重复初始化数据库或覆盖配置。

1. 安装 Node.js、npm 和 MySQL。前端使用 Vite 8，Node.js 需满足其版本要求（20.19+ 或 22.12+），建议使用受支持的 LTS 版本。
2. 在新的 MySQL 环境中执行 `database/schema.sql`，创建 `math_path` 数据库和基础表。后端启动时会检查并补充部分功能表结构，因此数据库账号需要相应建表、改表权限。
3. 在 `server/` 和 `client/` 目录中分别运行 `npm install`。
4. 将 `server/.env.example` 复制为 `server/.env`，再填写本机数据库连接与随机生成的 JWT 密钥。模板中的值仅为占位内容，不能直接作为实际配置。已有环境请保留原 `.env`，不要覆盖。

首次安装时，在项目根目录的 PowerShell 中执行：

```powershell
Copy-Item server/.env.example server/.env
```

配置字段如下：

```dotenv
MYSQL_HOST=127.0.0.1
MYSQL_USER=你的数据库用户名
MYSQL_PASSWORD=你的数据库密码
MYSQL_DATABASE=math_path
JWT_SECRET=替换为随机生成的长密钥
PORT=8005
CLIENT_ORIGIN=https://shuyoufang.asia
```

5. 在云服务器部署后端和前端静态文件，通过正式域名访问。
6. 新数据库首次使用时，在项目根目录运行以下命令，按提示设置管理员账号、昵称与密码：

```powershell
npm --prefix server run init:admin
```

密码输入不显示，也不需要写进命令或提交到仓库。命令只创建首位管理员；数据库已有管理员或账号已占用时会拒绝，不用于重置密码或提升学习账号权限。请先导入数据库结构；本项目没有公开的默认管理员密码。

7. 登录管理端，在「服务状态」中配置文字 AI、邮件及生图服务。注册、验证码登录和找回密码需要邮件服务可用。

### 下载代码与安装依赖

以下命令适用于已安装 Git、Node.js 和 npm 的新环境：

```powershell
git clone https://github.com/wangwenzhi679-blip/shuyoufang.git
cd shuyoufang
npm --prefix server ci
npm --prefix client ci
```

`npm ci` 根据各目录的锁文件安装依赖。数据库初始化可在 MySQL 客户端中执行：

```sql
SOURCE C:/项目所在路径/shuyoufang/database/schema.sql;
```

将路径替换为实际位置，建议使用正斜杠。脚本默认创建并使用 `math_path` 数据库；自行改名时需同时调整脚本和 `.env`，不要对重要数据执行未经核对的初始化。

### 文档处理依赖

添加课程时，提交后资料在后台导入，可继续浏览站内其他页面；页面上的“资料导入”任务显示进度、完成结果和失败重试。文件上传完成后，刷新页面不影响服务器继续解析，服务重启也会恢复未完成任务。文件仍在上传时请勿刷新或关闭页面。导入失败会保留课程与原文件，重试无需重新创建课程。

PDF 导入采用独立线程提取自带文字，避免构造整本文档版面及整本 OCR；扫描内容保留为原图供章节识别。删除课程会中止对应导入与生成任务。图片分批分析使用紧凑输出和受控并行，完整目录按资料、模型及整理要求缓存。[提速验证记录](docs/performance-check.md)列出测试方法及样例耗时。

资料分析、分章节、总结、练习、笔记和计划默认使用个人“助手设置”选择的文字模型；选择“跟随平台配置”时使用管理端当前启用的 API 与模型。图片生成使用独立的生图设置。后台代重试也按任务所属用户的设置执行。若选中模型不支持图片输入，会明确提示，不会自动切换到其他模型。

PDF 章节目录按原页图片识别：每页划分为上下重叠区域，每批处理 3 页，保留原 PDF 页码后汇总目录，不再仅以开头几页图片辅助长 OCR 文本。章节草稿保存对应的原页范围，采用目录后，章节正文直接显示这些页的图片，保留原始排版；阅读时按需加载图片。保存前检查完整页码覆盖，拒绝遗漏、重叠或越界的映射。分批结果按文件内容与模型缓存，失败重试可复用已完成批次。一次最多处理合计 300 页；较长资料会增加识别耗时和外部模型费用。此流程需要已配置的文字 AI 服务支持图片输入，识别摘要仍需人工核对。章节总结与其他学习功能沿用各自的现有处理路径。

DeepSeek 图片识别与目录结构化输出显式使用 JSON 模式及非思考模式，避免长思考占用受限的输出预算；普通问答维持原有模式。批次输出被截断或结构校验失败时，先重试，再自动拆为逐页识别，完整覆盖全部页码后才继续保存目录。目录生成、缓存及采用统一支持最多 300 章，按原资料结构组织，不再固定限制为 20 章；PDF 页码仍须完整、有序且无重复。图片识别完成后会显示目录汇总与页码校验阶段。

目录保存使用事务，失败会回滚并保留旧草稿；分析期间删除或替换资料时拒绝保存过期结果。删除资料会中止相关课程的生成任务。原页图片并发请求共享渲染，完整生成后才发布，损坏缓存可以重建。网络、超时和鉴权问题不会反复拆页请求，错误会明确提示原因。[导入与分章稳定性说明](docs/pdf-import-reliability.md)记录故障原因、恢复方式与验证范围。

### 课本显示比例

在章节“学习资料”及资料分页阅读中，可通过“课本比例”调整原页图片大小。默认 **100%**，表示适合当前阅读区域的宽度；可自由输入 **1%–1000%** 的比例，支持小数，例如 `72.5%`、`137.5%`。输入后按回车或移开焦点应用，也可使用加减按钮调整，点击“重置”恢复 100%。

放大后可横向滚动查看，翻页时保留当前比例；重新打开阅读区时恢复默认比例。此选项只改变课本页面的显示大小，不改变原文件、资料处理范围或 AI 生成内容。

### PDF 与 Office 运行依赖

- PDF 原页渲染使用 Poppler，配置方式见下方代码维护说明。
- Office 预览和笔记 PDF 导出需要可用的浏览器。Puppeteer 安装过程通常会下载配套浏览器；下载失败或环境不提供浏览器时，可在 `server` 目录运行 `npx puppeteer browsers install chrome`，也可通过 `PDF_RENDERER_EXECUTABLE` 指定已安装浏览器的可执行文件。
- Linux 环境还需要浏览器所需的系统库；仅安装 Node.js 依赖不代表文档转换已经可用。
- 配置后用一份 PDF 和一份 DOCX 实际检查导入、原页阅读与预览，再检查笔记导出。AI、邮件和生图连接需分别验证，不以网页能打开代替全部验收。

`JWT_SECRET` 同时用于相关服务密钥的加密，已有环境不要随意更换。`.env` 中的实际密码和服务密钥应私下保存，不写入 README 或公开仓库。

后端测试位于 `server/*.test.mjs`，多数集成测试需要 MySQL、已配置的测试环境及运行中的后端。不要在不了解测试影响时对重要数据直接运行全部测试。

## 代码维护

根目录使用固定版本的 Prettier，格式规则见 `.prettierrc.json`，缩进和换行规则见 `.editorconfig`。

模块职责、命名、注释、接口处理及提交前验证要求见 [代码结构与维护规范](docs/code-standards.md)。

```powershell
# 在项目根目录安装维护工具
npm install
# 检查格式；需要整理时运行 npm run format
npm run format:check
# 在 server 目录运行后端测试，依赖已配置的数据库和运行中的后端
npm --prefix server test
# 运行前端与共享逻辑的单元测试
node --test client/src/*.test.mjs shared/*.test.mjs
```

PDF 原页阅读需要 Poppler。后端优先使用 `PDFINFO_PATH`、`PDFTOPPM_PATH` 指定的可执行文件，也支持 `POPPLER_BIN` 目录和系统 PATH；Windows 上可以复用本机桌面运行时已提供的工具。调整工具配置后需重启后端。

## 数据保存与备份

课程、章节、笔记、练习、错题和计划等数据存储在 MySQL；原资料、笔记图片、课程封面和章节配图等文件位于 `server/storage/`。资料和预览目录可以通过 `UPLOAD_DIR`、`PREVIEW_DIR` 调整。

仅复制代码无法完整迁移学习数据。迁移时应同时保留数据库、实际文件目录和私下保存的配置。浏览器本地草稿及对话也应另行确认，不要默认已包含在服务端备份包内。

管理端提供备份功能；重要备份应下载并另存，恢复前先在独立环境核验。具体存储位置与手动备份方法见 [备份与恢复](docs/备份与恢复.md)。

## 常见问题

| 情况                     | 检查方式                                                                         |
| ------------------------ | -------------------------------------------------------------------------------- |
| 网页打不开               | 确认网络正常，并访问 https://shuyoufang.asia                                     |
| 页面打开但数据加载失败   | 确认后端 8005 端口及 MySQL 正常，查看后端错误提示                                |
| 数据库提示 Access denied | 核对 `server/.env` 中的用户名、密码和 MySQL 账号权限                             |
| 找不到 node 或 npm       | 本机可使用上述 `D:\node.exe`、`D:\npm.cmd`；其他电脑检查安装与 PATH              |
| 注册或验证码失败         | 在管理端检查邮件服务配置和发送结果                                               |
| AI 无法生成内容或图片    | 检查对应服务是否启用、连接结果、模型权限、余额和平台限额；文字与图片服务分别配置 |
| 忘记数据库密码           | 查看私有的 `server/.env` 中 `MYSQL_PASSWORD`，不要把整个配置文件公开发送         |

前端接口统一由 `client/src/api-base.mjs` 配置，默认通过 Vite 代理访问 `/api`；需要独立 API 地址时可配置 `VITE_API_BASE`。当前启动方式仍面向本机开发，公网部署还需要单独配置静态文件服务、反向代理与访问保护。
