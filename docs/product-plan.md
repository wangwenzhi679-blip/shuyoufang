# 数有方 · 产品规划

更新日期：2026-10-18  
适用范围：用户端、管理端及配套服务。本文作为产品主规划；专项文档提供具体操作与实现说明，历史改动见 [项目改动记录](change-log.md)。

## 1. 产品定位

数有方是面向大学生与个人自主学习者的 AI 课程学习平台。用户从自己的学习资料出发，整理课程、阅读章节、提问、记笔记、练习并复习，让学习内容与学习记录保持关联。

产品采用中式研习空间的视觉语言，同时保持年轻、清晰、易用。AI 用于辅助理解、整理与练习，用户保留内容采用、修改和学习完成的决定权。

当前围绕个人学习与平台运行管理展开，教师授课、班级管理、考试发布和多人协作不属于本阶段范围。

## 2. 核心学习流程

导入资料创建课程 → 整理和确认章节 → 阅读与记录 → 围绕资料提问 → 生成练习并作答 → 交卷查看反馈 → 收录错题与安排复习。

学习计划贯穿上述流程：根据目标与可用时间安排任务，首页承接今日学习，课程与章节保留进度、笔记和历史记录。

## 3. 当前页面与入口

顶部主导航包含学习首页、我的课程、AI 助手、错题复习、学习计划。搜索、头像及设置位于顶部账号区域。课程内部提供资料、章节总结、笔记和练习等入口。

| 页面或区域     | 当前职责                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| 用户登录与注册 | 登录、注册、找回密码及进入学习空间                                       |
| 学习首页       | 今日信息、连续学习、继续学习、今日任务、最近学习、更多学习记录与最近交卷 |
| 我的课程       | 浏览课程、导入资料创建课程、管理名称、简介与封面                         |
| 课程与章节     | 管理章节、阅读资料、查看总结、编辑笔记、生成与完成练习                   |
| AI 助手        | 选择研习范围、管理独立对话、查看引用、将回答转为笔记或练习               |
| 错题复习       | 错题本、掌握状态、重新作答和复习安排                                     |
| 学习计划       | AI 制定计划、预览采用、调整任务及记录完成情况                            |

## 4. 用户端功能

### 4.1 账号与个人设置

- 支持账号登录、邮箱相关验证、个人资料修改及密码管理，邮件流程依赖可用的邮件服务。
- 数据按账号隔离；切换账号后加载对应账号的数据与偏好。
- 头像附近提供个人资料与设置入口，账号切换和退出各保留一个清晰入口。
- 设置集中管理界面与阅读字号、学习偏好、文字模型和生图模型偏好；可选模型来自实际开放的服务。
- 设置子页返回入口放在左侧，保存失败保留输入，有未保存修改时提供继续编辑的选择。

### 4.2 学习首页

- 顶部展示随日期和时段更新的问候，以及依据学习记录计算的连续学习情况。
- 继续学习展示真实课程、章节及进度，进入后恢复对应学习位置。
- 今日学习展示计划任务；勾选成功后先显示对勾，再逐渐透明并收起，后续任务自然上移。保存失败不能伪装完成。
- 最近学习按实际记录展示，缩略图使用对应内容的章节配图。
- 更多学习记录与最近交卷保持独立、紧凑，展开后提供实际内容及明确跳转。
- 最近交卷打开选中的那次答卷，不统一跳转到最新答卷。
- 无数据时展示适量引导，不填造学习量、成绩、课程或任务。

### 4.3 课程、章节与资料

- 支持从资料创建课程，编辑课程名称与简介，管理课程封面及删除课程。
- 当前直接导入范围为 PDF、DOCX、PPTX；其他格式需先转换。
- 资料库提供继续导入、改名、提取文字查看、原文预览、下载和删除。
- AI 整理目录后由用户确认采用；章节也可手动添加、编辑、删除和调整插入位置。
- 阅读记录与书签关联账号、课程和章节，保留可恢复的位置。
- 原文件预览与提取文字分开：原页用于保留版式、公式和图片，提取文字用于整理和检索。
- 无法定位章节或原页加载失败时，提供阅读原文或重试入口。
- 章节完成标记、课程进度与计划阅读任务按已有规则联动，取消完成不抹除原阅读位置。

### 4.4 学习助手

- 左侧研习档案管理课程、章节范围、新建与历史对话；右侧承担问答与阅读，底部集中输入和发送操作。
- 对话按学习范围独立保存，可重命名、删除与恢复，刷新后读取服务端记录。
- 回答结合可访问的课程资料，展示实际可取得的来源；资料不足时说明缺少依据。
- 支持流式回答、停止、失败重试及重新生成；失败或停止不能显示为完整回答。
- 支持复制、加入笔记及依据回答生成练习，生成内容先按对应流程预览或采用。
- 切换课程或对话后，返回结果仍属于原对话，不能串入当前讨论。

### 4.5 章节总结与学习笔记

- 章节总结依据当前章节资料生成摘要与知识点，保存来源和更新时间，重新生成失败保留旧结果。
- 每章一份学习笔记，支持富文本、图片、原文摘录、重点与疑问、自动保存及恢复版本。
- 支持 AI 整理和生成笔记，预览后追加或替换，不直接覆盖用户内容。
- 边读边记与笔记页面使用同一份内容；宽屏并排，窄屏调整为适合阅读与输入的布局。
- 支持笔记导出，实际格式与运行要求见专项说明。

### 4.6 练习与交卷

- 依据当前章节生成练习，提供快捷模板与自定义题型、数量、难度及补充要求。
- 支持单选、多选、判断、填空与简答；生成结构校验失败时不保存为正常练习。
- 新练习不覆盖旧练习；未交卷答案保存为进行中的作答。
- 交卷前隐藏答案、对错和解析；交卷后保存完整答卷并集中展示结果。
- 再练一次开启新一轮，保留历史答卷；重复提交不产生重复交卷记录。
- 填空与简答的现有标准答案比对不等同于 AI 语义评分。

### 4.7 错题与间隔复习

- 交卷后由用户选择收录已作答的错题，同一道来源题去重。
- 支持课程、章节、待复习和已掌握筛选，重新作答及手动掌握管理。
- 复习安排位于错题复习页面，可单次安排或采用间隔复习，并支持修改日期、取消与提交结果保存。
- 当前间隔节点为第 1、3、7、14、30 天，统一以所选首次复习日为第 1 天，不把每一轮作为新的起点。
- 曲线用于解释复习节奏；示意数值不作为个人真实记忆保持率或效果承诺。
- 课程学习计划与错题复习安排分别管理，首页提供对应任务入口。

### 4.8 学习计划

- 根据真实课程章节、目标日期和可用时间生成计划，用户预览、调整后采用。
- 一门课程同时保留一份进行中的计划，支持编辑、改期、重排和删除。
- 重新规划保留已完成任务；打开页面不直接算完成。
- 没有现成练习时提供出题入口，不生成指向不存在练习的任务。
- 任务进度使用实际保存的数据，不把 AI 预估时间当成真实学习时长。

### 4.9 封面与章节配图

- 课程提供书名自动排版封面，可上传替换或主动 AI 绘制，并预览采用。
- 课程列表与继续学习复用同一课程封面。
- 章节配图依据课程名、章节名构图，首次访问新章节时按服务状态与限额触发生成，已存在的图片复用。
- 设置中的配图管理集中提供查看、提出本次要求、生成候选和采用入口，不在首页缩略图上叠加遮挡内容的菜单。
- 自动章节配图输入限定为课程名与章节名；手动重绘增加用户本次填写的要求，不额外发送课程正文、笔记和对话。
- 失败保留原图或可用占位，不能反复刷新就无限发起付费请求。文字 AI 与生图服务分别配置。

## 5. 管理端功能

管理端延续用户端纸色、墨色、青绿与朱红的视觉体系，优先保证列表、筛选、详情及异常处理清晰。

| 模块       | 当前能力                                               |
| ---------- | ------------------------------------------------------ |
| 管理概览   | 平台统计、异常概况和存储核查                           |
| 用户管理   | 查询、详情、停用、恢复及注销学习账号                   |
| 课程与资料 | 查询筛选、详情、暂停与恢复、文件与预览状态、预览修复   |
| AI 任务    | 任务状态、脱敏诊断、取消、符合条件的重试               |
| 公告       | 编辑、发布及管理公告                                   |
| 服务状态   | 文字 AI、邮件与章节配图配置、连接检查、状态及用量信息  |
| 运行设置   | 上传大小、批次数量、AI 并发与相关服务开关              |
| 数据备份   | 手动创建、状态与体积、下载、独立恢复验证及删除历史备份 |
| 操作日志   | 搜索、筛选及查看操作对象、处理原因和结果               |
| 管理员账号 | 个人设置与密码修改                                     |

管理规则：

- 注销学习账号与停用不同：注销不可恢复，撤销登录并解绑邮箱，保留账号名称和相关学习记录供管理核查；不是物理清空全部记录。
- 管理员账号不通过学习账号注销入口处理。多管理员权限分级仍为后续事项。
- 修改操作由后端鉴权并检查版本，多窗口冲突时提示刷新，不静默覆盖。
- 任务重试检查原输入、资料版本和当前对象状态；取消后阻止迟到结果继续写入。
- 诊断及日志不明文暴露密码、服务密钥或无关用户正文。
- 备份恢复验证使用独立环境，不等于提供在线覆盖恢复功能；备份不能替代部署配置与密钥的单独保管。

## 6. 统一视觉与交互

- 保持宣纸底色、墨色正文、浅青绿辅助色与少量朱红，书卷感与现代学习工具的可读性并重。
- 产品名、导航、页面标题、卡片和正文建立一致层级，装饰不遮挡表单、按钮与阅读内容。
- 参考图用于布局、比例与画风，不以整张页面图片替代真实文字、表单和交互。
- 用户端弹窗沿用设置弹窗的纸笺风格，统一标题、返回与关闭入口、内容间距和底部操作。
- 弹窗依据用途调整宽高；低视口优先滚动内容区，主要按钮可见。
- 确认、删除、编辑与生成要求均在网页内完成，错误保留输入；提交中防止重复操作。
- 支持键盘焦点、合理的返回层级与减少动画偏好。嵌套弹窗先处理最上层。

## 7. 数据与生成任务

- 学习记录、笔记、答卷、对话、计划、偏好和任务状态以服务端持久化为主；浏览器草稿不等于已保存成功。
- 目录整理、章节总结、练习、笔记与计划等生成任务使用已有服务端任务机制，页面切换或刷新后可查询状态。
- 服务重启不会自动续跑已中断的生成；中断任务标记失败，由用户或符合条件的管理员发起重试。
- 保存阶段、取消、失败与完成应准确区分，旧内容在新结果成功前保留。
- 删除课程、章节或练习时，关联记录按对应删除规则处理，界面同步移除失效入口。
- 日期统一格式化，缺失时间明确提示，不补造历史值。

## 8. 当前使用条件与边界

- 当前启动方式面向本机开发，前端 5173、后端 8005，数据库使用 MySQL。
- 文字 AI、邮件和生图分别依赖有效的服务配置、权限与额度。
- 文档解析、OCR、PDF 原页和预览效果受文件结构与运行依赖影响，不承诺所有扫描件、复杂公式与版式均准确。
- 已有响应式样式不等于已完成真实手机验收，移动端仍需逐页检查。
- 主体学习流程和管理模块已有实现；上线可用性需结合目标服务器与实际服务配置重新验收，不能以本地构建成功代替。

## 9. 后续优先级与验收

### 第一优先：移动端使用

- 检查导航、课程列表、章节阅读、AI 对话、答题与计划页面的窄屏布局。
- 检查侧栏收起、长标题、横向溢出、触摸操作和虚拟键盘遮挡。
- 检查弹窗内容与底部按钮、PDF 缩放、图片上传和返回行为。
- 先用浏览器设备模拟，再用真实手机验证，不仅凭静态截图确认适配。

### 第二优先：部署与对外试用

- 准备部署配置、数据库初始化及管理员初始化步骤。
- 构建正式前端，由静态文件服务提供网页并代理后端接口，验证深层链接刷新与流式回答。
- 配置 HTTPS、服务自动启动、文件持久存储和备份，保留升级与故障回退办法。
- 新环境验证注册与邮件、课程导入、预览、AI 问答、练习交卷、配图及管理端权限。
- 迁移使用数据库与文件共同核验，不把直接复制代码视为完整迁移。

### 第三优先：持续完善

- 根据真实使用反馈调整复习曲线、信息密度和学习路径，避免新增重复入口。
- 在独立测试环境进行回归验证，维护工作不向正式平台写入测试账号和记录。
- 随资料规模与调用量增长检查存储查询、后台任务、备份耗时及模型请求资源占用。
- 多管理员分级、自适应复习和更深入的学习分析另行规划，未实现前不写成现有能力。
