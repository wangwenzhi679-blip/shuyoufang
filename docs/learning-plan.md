# AI 学习计划功能规划

更新日期：2026-10-05  
状态：第一版已实现并验证。

## 1. 功能目标

面向个人自主学习者，由 AI 根据课程现有章节和用户可用时间安排学习任务。用户预览、修改并确认采用后，从学习首页进入今日任务，完成学习后记录进度。

核心流程：填写目标 → AI 后台生成 → 预览和调整 → 确认采用 → 执行今日任务 → 勾选完成 → 按需顺延或重新规划。

## 2. 已确认的基本规则

- AI 帮助安排计划，用户可以修改后采用。
- 一门课程同时只保留一份进行中的计划，避免重复任务。
- 生成结果需要用户确认采用后才成为正式计划。
- AI 生成期间可以继续使用网站其他功能。
- 任务由用户手动勾选完成，仅打开页面不算完成。
- 重新规划时保留已完成任务和记录。
- 没有练习的章节只安排学习内容，并提供出题入口，不显示不存在的练习。

## 3. 创建计划

用户选择一门课程，填写以下内容：

| 字段         | 用途                                           |
| ------------ | ---------------------------------------------- |
| 目标完成日期 | 希望在什么时候完成学习                         |
| 每周学习安排 | 每周学习几天，以及适合学习的日期               |
| 每天可用时间 | 帮助控制每日任务量                             |
| 向 AI 提要求 | 补充薄弱章节、复习重点或学习节奏等要求，可不填 |

AI 依据课程真实章节安排任务。课程没有章节时，应引导用户先整理章节。时间过紧时应说明安排可能不合理，允许用户调整日期或任务量，不承诺一定能完成。

## 4. 生成、预览与采用

1. 在弹窗中填写目标和要求，提交后启动后台生成。
2. 显示生成状态，允许切换课程或使用其他功能。
3. 完成后提供查看入口，按日期展示任务。
4. 用户可以修改任务日期和内容，或填写新要求后重新生成。
5. 用户点击“采用计划”后，计划才进入进行中状态。
6. 已有进行中计划时，重新安排通过更新该计划完成，不另建重复的进行中计划。

生成失败时保留输入条件并提供重试。未采用的新结果不覆盖现有计划。

## 5. 学习任务

| 类型     | 内容与入口                       |
| -------- | -------------------------------- |
| 阅读学习 | 进入指定课程和章节，阅读已有资料 |
| 整理笔记 | 进入指定章节的学习笔记           |
| 章节练习 | 有现成练习时提供实际练习入口     |

没有练习时，提供“生成练习”入口，由用户操作出题；不能把不存在的练习作为可直接作答的内容。

每项任务应清楚展示日期、所属章节、任务内容和完成状态。时间安排属于估算，用户可以按实际情况调整。

## 6. 今日任务与进度

- 学习首页展示今日任务，点击可进入对应内容。
- 提供查看完整计划的入口。
- 用户手动勾选完成，也应能纠正误勾选。
- 进度按已完成任务数与总任务数展示，不等同于知识掌握程度。
- 刷新页面或重新登录后，计划及完成状态仍应保留。
- 多门课程的今日任务需显示课程名称，避免混淆。

## 7. 顺延和重新规划

- 未完成任务可顺延，避免直接丢弃。
- 重新安排前提供预览，由用户确认后应用。
- 保留已完成任务和原有完成记录，仅调整剩余安排。
- 顺延超出目标完成日期时提示用户调整目标日期或剩余任务量。
- 课程章节或资料删除后，应说明相关内容已不可用，不能跳到错误的内容或继续展示失效入口。

## 8. 页面与交互原则

- 延续现有蓝色界面，保持紧凑的排版和清晰的任务层次。
- 添加、修改和删除类操作沿用统一弹窗；取消与保存按钮大小一致。
- 创建条件使用弹窗，计划预览和日常任务展示应便于阅读和修改。
- 浏览器前进、返回以及页面刷新遵循现有页面状态恢复规则。
- 所有新增文案使用简体中文。

## 9. 技术方向

沿用项目现有 React、Vite、Node.js、Express、MySQL 和官方 DeepSeek API。

- 计划、任务、完成状态和生成任务保存到数据库，并按账户隔离。
- AI 返回的章节引用、日期及任务类型必须校验，不能直接信任生成结果。
- 服务端保证同一课程只有一份进行中计划，避免重复提交或多窗口操作创建重复计划。
- 后台生成任务应支持查看结果和失败重试；采用前校验课程及计划是否已变化。
- 具体接口、表结构和页面布局在开发阶段细化。

## 10. 第一版范围

包含 AI 安排、预览修改、确认采用、今日任务、手动完成、进度、顺延和保留完成记录的重新规划。

第一版暂不加入提醒推送、复杂日历、打卡排名和多人教学管理。

## 11. 验收标准

1. 能根据真实章节和用户要求生成可预览的学习计划。
2. 生成期间可以使用其他页面，完成后能够查看结果。
3. 未采用的结果不影响现有计划，同一课程不会出现重复的进行中计划。
4. 今日任务能进入正确章节、笔记或已有练习；不存在的练习不产生虚假入口。
5. 完成状态能保存并恢复，访问页面不会自动标记完成。
6. 未完成任务可以顺延，重新规划保留已完成记录。
7. AI 失败、章节删除或计划并发修改时给出明确提示，不静默覆盖数据。

## 12. 第一版实现与验证记录

实现日期：2026-10-05。

- 左侧新增“学习计划”，首页新增今日任务；过期未完成任务也显示，首页最多展示八项并提供完整计划入口。
- 条件弹窗支持选择课程、目标日期、每日时间、每周学习日和向 AI 提要求。使用官方 DeepSeek 接口后台生成，切换页面不会中断任务。
- 生成结果先预览，日期、章节、类型、内容和预计分钟均可修改；确认采用后保存。取消或生成失败不覆盖原计划。
- 阅读、笔记、练习任务进入对应章节。没有资料或练习时提供导入或出题入口，不编造内容。
- 手动勾选与取消完成，数据库保存进度；刷新保持学习计划页面与完成记录。
- 调整及重新规划保留已完成记录。顺延从今天起安排过期任务，未来任务不提前；超过原目标日期时延长并提示，确认后保存。
- 每课程保存一份当前计划。账户隔离、版本校验、事务锁防止并发操作覆盖记录；章节变化后旧生成结果不可直接采用。
- 章节删除时标明不可进入；生成中服务重启将任务标为失败，可重新生成，原计划保留。

### 支持范围

目标日期限未来一年，每日时间 10 至 480 分钟。AI 每次最多生成 150 项任务；预计时间仅用于安排，超出每日预算显示提示，不是实际学习计时。后台状态每五秒刷新。第一版不提供通知推送及复杂日历。

### 验证结果

服务端集成测试验证后台生成、重复提交、确认采用、版本冲突、完成状态、完成记录保留、账户隔离、日期与章节校验以及已删除章节的显示。全部五组服务端测试通过，前端生产构建通过。

浏览器使用临时账户和独立测试课程，真实调用 DeepSeek，验证生成期间切换课程页、预览采用、完成勾选、刷新恢复、笔记任务定位和顺延保存。测试数据已清理，未修改用户课程。

## 2026-10-07 文档补充核对

已提供删除计划确认弹窗及服务端删除接口，按账户和版本校验。删除计划会移除其任务、完成记录和相关待采用结果，保留课程、资料和笔记。手动错题复习安排存放在独立表中，入口已统一移到错题复习页，删除或重新规划课程计划不影响这些安排。

### 2026-10-08 学习计划操作名称简化

计划卡片操作统一为：编辑、改期、重排、删除。编辑用于手动调整未完成任务；改期从今天起重新安排剩余任务日期；重排向 AI 提要求重新制定计划。按钮悬停显示完整用途，保留原有预览和删除确认流程。

### 2026-10-08 学习计划完成百分比

学习计划卡片显示“学习进度 XX%”、进度条及完成数量。百分比按已完成任务数除以总任务数计算，四舍五入为整数；空任务显示 0%。勾选或取消完成后使用更新的任务记录计算，刷新后根据保存记录恢复。该指标表示计划任务完成比例。

### 2026-10-08 学习计划同步章节阅读进度

每项章节任务下显示章节阅读百分比与细进度条，与课程目录使用同一阅读记录；标记章节已学完显示 100%。完整计划与首页今日任务都显示，随现有五秒刷新更新。计划总进度名称改为“计划完成”，用于区分任务完成比例与章节阅读比例；勾选任务不会替代章节阅读进度。

### 2026-10-08 任务完成操作优化

学习计划与首页任务移除整行勾选操作，改为右侧固定宽度“完成”按钮。保存时当前按钮显示“保存中…”，完成后显示绿色“已完成”，再次点击可撤销；保留服务端版本校验、失败提示和刷新恢复。任务标题不再划线，左侧圆形状态标识辅助区分，章节阅读进度独立保留。逾期提示改为“待补学”。

### 2026-10-08 任务完成百分比规则修正

学习计划任务行改为显示“任务进度”：记录完成后显示 100%；撤销完成后恢复该章节保存的阅读百分比。刷新后根据服务端完成记录显示。此规则取代此前任务行始终显示章节阅读比例的规则，课程目录的真实阅读记录保持独立。

### 2026-10-08 首页隐藏已完成任务

今日学习任务仅显示今天及之前未完成的任务。完成后从首页移除，完整学习计划仍保留完成记录；撤销完成后再次进入首页待完成列表。此规则替代首页保留当天已完成任务的规则。
