# 课程封面与配图管理

更新日期：2026-10-16  
状态：已实现。

## 一、入口与管理范围

用户端入口为“头像旁齿轮 → 学习 → 管理配图”，窗口内分为“课程封面”和“章节配图”。支持课程或章节关键词搜索、分页与返回设置。首页缩略图不叠加三个点菜单，管理端不增加逐课程更换图片入口。

课程封面用于“我的课程”和首页“继续学习”；章节配图用于章节主题插画和最近学习缩略图。两者独立保存，更换课程封面不覆盖章节图片。

## 二、课程封面

本轮落实用户确认的第 2、3、4 项：自动排版与可选 AI 绘制、自选上传、统一管理和同步显示。自动提取 PDF 第一页或选择原文页作为封面未纳入本轮。

### 自动书名排版

- 无图片时直接按课程名显示书封，包含书名、学科图形与书卷排版，采用宣纸底色和低饱和配色。
- 自动书封使用真实文字和图形排版，无需调用生图服务；新导入和已有课程都可显示。
- 课程更名后，自动排版封面随名称更新；自选或 AI 图片不因改名自动替换。
- 用户可通过“书名排版 → 使用排版封面”恢复自动书封。

### 上传图片

- 支持选择 PNG、JPG、WebP；先在本地压缩成 JPG 并显示预览，点击“使用这张封面”后才上传采用。
- 本地选择限制 10MB，压缩后最长边不超过 1000px。服务端接收压缩后的 PNG/JPG，限制 3MB，并检查图片编码、实际格式、尺寸与有效图像数据。
- 小尺寸 JPG 正常支持；损坏或伪装文件不能作为封面保存。上传失败保留选择结果，可重试。
- 按竖版书封区域完整显示图片；不会把原文件内容或整本教材上传到生图服务。

### AI 绘制

- 用户主动点击“生成封面”后后台绘制，可填写最多 500 字的本次要求。生成期间可关闭窗口继续学习。
- 只发送课程名和用户本次绘画要求，不发送课程简介、教材正文或账号信息。
- 使用现有配图服务配置，与章节配图共享每日额度和全局暂停控制。
- 新封面先保存为候选；预览后可“采用新封面”或“保留原封面”。生成失败、暂停或超时都不替换当前封面。
- 手动生成失败不自动发起下一次付费请求。取消尚未调用供应商的任务时，不发起生图请求，并归还已预留但未使用的当日额度。
- 上传图片或恢复排版封面会取消旧候选；生成中的旧结果不会覆盖新的封面。

## 三、章节配图

- 在“章节配图”页选择章节，进入调整窗口；查看当前图片和新图预览。
- 提供“水墨更淡、突出概念、重新构图”快捷要求，以及最多 500 字的自定义要求。
- 用户主动重新生成后保留原图，新图完成后才允许采用或放弃。后台任务按原账号处理，不强制跳转当前学习页面。
- 手动调整只发送课程名、章节名和本次要求；自动首次配图沿用课程名、章节名主题生成。
- 名称变化、旧结果、重复提交及当前图片已变化等情况由服务端检查，避免采用不对应的候选图。

## 四、同步与保存

- 课程列表和首页使用同一个课程封面组件，采用、上传或恢复排版后立即通知当前页面刷新；重新进入或刷新后从服务端恢复。
- 网络失败提供重试；当前封面已被其他页面改变时刷新状态，并提示用户查看后重新确认，不直接覆盖。
- 图片读取、上传和候选操作均按课程所有者鉴权；列表只返回本人课程。普通学习账号不能通过修改编号访问他人封面。
- 课程删除后级联删除封面记录，并清理当前封面及候选文件；在途任务不能留下已删除课程的图片产物。

## 五、存储与代码位置

| 内容               | 位置                                              |
| ------------------ | ------------------------------------------------- |
| 当前课程封面与来源 | MySQL 表 `course_covers`                          |
| 课程封面候选任务   | MySQL 表 `course_cover_drafts`                    |
| 当前章节配图与候选 | MySQL 表 `chapter_images`、`chapter_image_drafts` |
| 共享每日用量       | MySQL 表 `chapter_image_usage`                    |
| 课程封面图片       | `server/storage/course-covers`                    |
| 章节配图图片       | `server/storage/chapter-images`                   |
| 课程封面服务       | `server/course-covers.js`                         |
| 共用课程封面组件   | `client/src/CourseCover.jsx`                      |
| 课程封面管理       | `client/src/CourseCoverManager.jsx`               |
| 设置弹窗样式       | `client/src/settings-paper.css`                   |

AI 新封面和章节配图需要管理端已配置并启用的生图服务。自动书名排版与本地图片上传不依赖 AI 服务。
