### 2. 登录页具体实现

- 桌面采用左右分栏：左侧为水墨画面和主题文字，右侧为真实登录表单。表单视觉宽度建议 360–420px，总内容宽度建议 1120–1280px，根据参考图微调。
- 页面底色为柔和宣纸白，正文为深墨色，辅助文字为可读的灰色，朱红仅作少量点缀。不要继续混用旧版陶土棕按钮、蓝色按钮和杂志装饰。
- 左侧可使用“学而有方，思而有得。”，产品名使用“数有方”。参考图中无法辨认的文字不要猜写，删除无用的装饰文案。
- 竹、梅、山水等作为独立背景或装饰资源，不承载真实表单文字。不能把截图拉伸成背景并用透明输入框套位置；不能出现图片表单和真实表单双重叠加。
- 正文和输入控件使用清晰的中文系统字体；书法字体仅用于品牌或装饰主标题。字体加载失败时也必须正常显示，避免依赖外网字体才能阅读。
- 输入框、标签、错误提示、验证码按钮各自占据稳定空间。密码登录、邮箱登录、注册、找回密码均复用统一的布局规则。
- 墨色主按钮应有清晰文字、悬停、键盘焦点、禁用、提交中状态；保留已有防重复提交和错误反馈。
- 低高度窗口允许正常滚动，不强行把表单裁切。窄屏将装饰收起或移到上方，表单占可用宽度，不产生横向滚动。

### 4. 管理端具体要求

- 管理端使用相同的纸白、墨色和克制点缀，但表格和筛选保持工作界面的清晰密度。

- 表格标题、列名、数据、分页清楚分级；按钮尺寸统一，不把一行筛选撑成巨型卡片。
- 日期筛选继续使用日期选择器，保留查询、重置、角色、动作、结果等筛选能力。
- 保留完整的加载、空列表、失败重试、无权限状态。不要用固定数字或假数据美化页面。

- 管理端品牌保持静态，不要重新改为 href="/" 或 href="/admin" 导致刷新。

### 5. 设置弹窗不可回退的细节

- 当前桌面外框约 460px 宽、460px 高，保持小巧。切换外观、学习、AI 标签时外框不跳动。
- 调节站点字号不能放大设置弹窗的工具文字和外框；阅读预览可以体现所选字号。
- 内容过多时只滚动内容区，顶部标签、底部账号操作和底部保存操作保持稳定。
- “切换账号”“退出账号”在内容下方、取消保存上方的独立区域。两者尺寸一致，排列整齐，不散落到不同标签页。
- “取消”“保存”在右下角，宽高一致。退出账号使用适度的危险操作颜色，不能与保存混淆。
- 小屏时以视口为上限，关闭按钮和底部按钮始终可达。

### 6. CSS 与组件处理方式

- 先判断问题来自哪个组件和样式规则，再修改。避免在文件末尾不断追加互相覆盖的同名规则。

- 布局使用正常文档流、Flex 或 Grid。不要用大段绝对定位、负 margin 或固定像素坐标把主内容推到侧栏背后。
- 左侧导航若固定定位，正文必须留出匹配宽度；所有嵌套滚动容器处理 min-height: 0 和 min-width: 0。
