# 评审账号交付

网站入口：<https://shuyoufang.asia/>。Windows 1.0.2 默认连接同一网站，使用同一账号密码。

## 在部署服务器创建账号

在云服务器项目目录执行：

```bash
git pull --ff-only
node server/init-reviewer.mjs
```

脚本随机生成符合登录规则的普通学习账号和密码，不修改现有账号、管理员权限或学习数据。密码以哈希存入数据库。创建后通过已部署后端验证账号密码登录，再将私密测试说明写入 `startup-logs/评审体验账号-公网.txt`；该目录不提交 Git。

只有看到“评审账号创建及登录验证成功”，并通过正式网站实际登录后，才将说明私下交给老师。不要将密码或该文件放入公开仓库、技术文档或安装包。

重复执行时，如果私密说明已存在，脚本拒绝覆盖，不会重置密码或再建账号。若提示账号已创建但验证未完成，保留文件，先检查网站服务，不要删除文件反复创建。

## 交付与验收

- 本机旧测试账号及其课程不等于公网账号；旧说明中的课程清单不能当作云端已迁移的证明。
- 新账号初始没有课程，须先准备评审课程，再确认阅读、练习、错题复习及学习心得等演示内容。
- 在正式网站用账号密码登录，确认无管理员权限；Windows 可使用同一账号复测。
- 评审期间保持服务可用；结束后可在管理端停用该账号。

创建成功仅证明部署服务器上的登录接口通过。公网浏览器登录、课程内容和 Windows 体验仍需分别验收。
