# 后续功能规划：阅读进度、错题复习安排与全站搜索

更新日期：2026-10-07
状态：阅读进度与书签、错题复习安排、全站搜索第一版已实现。
适用项目：数有方——基于 AI 的课程学习与智能练习平台。

## 1. 目标与开发顺序

面向个人自主学习，让用户再次打开时能够接着阅读，按安排复习错题，并快速找到已有学习内容。

按以下顺序推进，每项完成后验证并体验，再进入下一项：

1. 阅读进度与书签。
2. 错题复习安排。
3. 全站搜索。

阅读进度与书签已按本规划进入实现，实际支持范围和验证结果见第 7 节。错题复习安排的实现与验证见第 8 节；全站搜索实现范围见第 10 节。

## 2. 阅读进度与书签

### 2.1 第一版功能

- 自动保存每个章节、每份资料的最近阅读位置。
- 再次进入时恢复到上次位置，首页“继续学习”和学习计划阅读任务接入同一恢复逻辑。
- 添加、改名、删除书签；点击书签定位到对应资料位置。
- 书签默认使用章节名、页码或所选文字的简短摘要，可在弹窗中修改名称。
- 书签列表放在阅读区域内，通过入口展开，保持当前章节目录布局。

### 2.2 使用流程

进入章节 → 阅读资料 → 自动保存位置 → 添加重要位置书签 → 离开 → 再次进入恢复位置。

通过书签进入时优先定位书签；通过“继续学习”进入时恢复最近位置。

### 2.3 保存与边界

- PDF 保存页码；章节文字保存段落标识和段内相对位置。具体定位字段在实现时结合阅读组件确定。
- 不同章节、不同资料分别保存，切换时互不覆盖；按账户隔离，保存到数据库。
- 阅读位置与学习完成状态分开，滚动到底不自动判定完成或掌握。
- 保存失败要提示，避免显示虚假的“已保存”；恢复位置应在内容加载后执行，避免先跳转再回到顶部。
- 资料修改后先尝试定位原位置；无法定位时提示位置已失效，并提供从开头阅读的入口。
- 资料被删除后，相关书签不再跳转到错误内容，应显示失效状态并允许删除。
- 无法追踪内部位置的外部阅读器只恢复资料入口，明确不保证页内定位。
- 多窗口保存不得让过期请求覆盖更新的位置；实现时采用版本或等效冲突保护。

### 2.4 验收标准

1. 阅读到中间后刷新、切换章节再返回，能够恢复对应位置。
2. 两份资料、两个章节的进度互不干扰。
3. 书签添加、改名、删除及跳转均可用，取消弹窗不改变数据。
4. 首页和计划阅读入口能恢复正确位置。
5. 资料变化、删除及保存失败有明确反馈，不定位到其他内容。
6. 阅读到底不会自动勾选学习计划任务。

## 3. 错题复习安排

### 3.1 第一版功能

- 在错题本选择一道或多道未掌握题目，设置复习日期，加入复习安排。
- 首页显示当天及逾期未完成的复习任务，点击进入对应错题练习。
- 复习后保存本次选择、判定结果和时间，可查看最近一次结果。
- 支持修改复习日期及取消安排，均通过弹窗确认。
- 不增加另一套题库，使用现有错题和答题记录。

### 3.2 使用流程

错题本选择题目 → 设置日期 → 确认复习安排 → 首页进入复习 → 提交答案 → 查看结果 → 更新复习记录。

### 3.3 业务规则

- 同一账户、同一道题、同一天不重复安排，重复添加时提示已有安排。
- 复习提交后记录任务完成；“任务已完成”和“题目已掌握”是两个状态，答对一次不自动标记掌握。
- 用户可继续沿用错题本的掌握操作；后续需要复习时可另选日期安排。
- 修改或取消未来安排不删除已有答题历史。
- 错题被删除后，相关未完成任务提示失效，不跳到其他题目。
- AI 重新规划课程学习时保留用户明确安排的错题复习，避免无提示覆盖。
- 尚无课程学习计划时也应允许安排错题复习，不能强迫先调用 AI 生成整份计划。实现时作为独立复习安排，由错题复习页的“复习安排”标签和首页到期提醒展示。
- 删除课程学习计划与取消错题复习安排应明确区分，删除确认中说明范围。

### 3.4 验收标准

1. 单题和多题均可安排，重复安排受到限制。
2. 到期任务可从首页进入，题干和选项完整。
3. 提交后保存结果，刷新及重新进入不会丢失。
4. 答对一次不自动标记掌握。
5. 改日期、取消及题目删除后的显示符合规则。
6. AI 重新规划不会丢失手动安排的复习任务。

## 4. 全站搜索

### 4.1 第一版功能

- 提供统一搜索入口，按关键词搜索课程名称、章节名称、资料名称及已提取文字、笔记正文和错题题干。
- 支持按课程、章节、资料、笔记、错题类型筛选结果，并可限定所属课程。
- 结果显示标题、命中内容摘要和所属课程；笔记同时显示章节，错题显示来源信息。
- 点击进入相应课程、章节、资料、笔记或错题；资料结果进入对应资料阅读入口，无法精确定位原文时不承诺命中页跳转。
- 返回搜索页时保留关键词、筛选条件及结果位置。

### 4.2 搜索规则

- 第一版采用关键词匹配，不接入 AI 语义搜索。
- 只搜索当前用户有权限访问的内容，服务器必须检查账户归属。
- 笔记搜索提取可见文字，不把富文本标签和图片编码当作正文。
- 已删除内容不再显示；点击前数据失效时给出提示。
- 空关键词不执行全文查询；没有匹配内容显示清晰空状态。
- 输入变化时适度延迟查询，旧请求结果不能覆盖新关键词的结果。
- 结果分页或分批加载，避免一次返回大量正文。
- 资料只搜索系统已经成功提取并保存的文字；扫描页已有 OCR 文字可参与搜索。不直接搜索图片像素，不在搜索时重新解析文件，也不保证覆盖原文件全部内容。

### 4.3 验收标准

1. 五类内容均能按关键词找到，并显示正确归属。
2. 点击结果定位正确，浏览器返回保留搜索状态。
3. 无结果、加载失败和内容被删除有明确提示。
4. 不同账户无法搜索到对方内容。
5. 快速修改关键词不会出现旧结果覆盖新结果。

## 5. 页面与技术约定

- 沿用 React、Vite、Node.js、Express、MySQL；复用现有课程、笔记、错题和计划数据。
- 新增数据由服务端持久化，浏览器缓存只辅助恢复，不作为唯一存储。
- 保持蓝色界面，操作紧凑；添加、修改、删除使用弹窗，取消和确认按钮大小一致。
- 遵守现有固定侧栏、独立内容滚动和浏览器前后导航规则。
- 文案及项目文档统一使用简体中文，开发文件继续保存在 E 盘。
- 接口、表结构与迁移方案在开发前结合现有代码细化，不把本规划中的建议视为已经实现。

## 7. 阅读进度与书签实现记录（2026-10-05）

### 7.1 已实现

- 章节学习资料进入后自动展开；独立阅读区按题目或段落标识及相对位置保存，刷新及切换章节后恢复。章节目录布局不变。
- PDF 分页阅读支持上一页、下一页、输入页码跳转，保存页码和页内滚动比例。原样页面由原 PDF 渲染，不使用 AI 重写公式或图片。
- 每个账户、章节、资料独立存储；章节文字使用资料编号 0 作为组合阅读范围，PDF 按实际资料编号保存。
- 添加、改名、删除书签均使用弹窗；取消不改数据。章节书签列表汇总该章节各资料的书签，点击 PDF 书签进入对应页码。
- 首页“继续学习”和计划中的阅读任务使用相同恢复入口；有最近 PDF 位置时打开该 PDF，否则展开章节文字。
- 刷新后恢复已打开的原资料阅读页；浏览器后退及前进继续使用原页面导航。
- 位置先在浏览器暂存，短延迟写入 MySQL；页面离开时尝试完成保存。刷新后仅恢复与服务器版本匹配的暂存位置。
- 服务器按版本检查保存，拒绝过期或并发覆盖；保存失败显示提示，不显示虚假的成功状态。
- 原位置的段落已经变化时提示失效并从开头展示；资料删除后书签显示“原资料已删除”，禁止跳转但仍可删除书签。
- 滚动到底不会自动勾选学习计划任务。

### 7.2 数据与接口

MySQL 新增 reading_positions、reading_bookmarks。位置按用户、章节、资料唯一；位置包含段落标识、序号、相对偏移及可选 PDF 页码。更新时间精确到毫秒；章节或账户删除时相关记录级联删除。

- GET/PUT /api/courses/:courseId/chapters/:chapterId/reading：读取位置、版本及书签；保存新位置。
- POST 同路径 /bookmarks：新增书签。
- PUT/DELETE /api/reading-bookmarks/:id：改名或删除本人书签。
- GET /api/courses/:courseId/materials/:materialId/reading-info：读取 PDF 页数。
- GET 同资料路径 /reading-page/:page：读取经过鉴权的原页图片。

### 7.3 支持范围及限制

- 分页阅读第一版最多支持 2000 页。PDF 页图片在本地缓存，资料删除时清理缓存。
- Word、PPT 沿用已有原样预览转换流程；转换成功后才能使用 PDF 分页定位。转换失败会提示，不声称已经保存原页位置。
- 分页阅读以页面图片保留版式、公式和插图，不能直接选择图片中的文字。需要复制可选择的文字时使用“原文件预览”，也可查看已有文字提取结果。
- “原文件预览”沿用浏览器阅读器；它内部的滚动或页码无法可靠追踪，只保留切换前的分页阅读位置。扫描页本身是否有可选择文字取决于原文件。
- 章节文字的位置基于提取结果定位，不保证原始文档中的所有版式。资料顺序或正文发生变化后，无法匹配的段落会提示位置失效。
- 网络或后端不可用时暂存不是服务器保存成功；多窗口版本冲突需要重新加载。

### 7.4 验证记录

- 前端生产构建通过。
- 六组后端回归测试全部通过；阅读专项覆盖章节隔离、账户归属、无效资料、位置验证、书签改名/删除、过期请求及并发冲突。
- PDF 保存页码及已删除资料书签状态、失效跳转保护通过接口测试。
- 浏览器使用独立测试账户验证章节中间位置刷新恢复、切换章节返回、书签新增与改名、取消删除不改变书签。
- 四页测试 PDF 验证第 3 页刷新恢复、书签跳转、浏览器后退/前进、首页继续学习进入对应 PDF；原文件预览和分页阅读可切换。
- 计划阅读入口已接入同一恢复调用；此次没有生成新 AI 计划来进行完整任务流程复测。
- 临时验证账户、资料及缓存在验证结束后清理，不保留到正式课程。

## 8. 错题复习安排实施记录（2026-10-07）

- 错题本支持选择单道或批量选择未掌握题目，使用弹窗设置复习日期。同一道题同一天避免重复安排。
- 学习首页显示今天及逾期未完成的复习任务；错题复习页的“复习安排”标签列出待复习与已完成记录。无需先创建 AI 课程计划。
- 复习页展示完整题干和选项，提交后显示对错与解析，保存答案、结果、完成时间和当时题目快照。刷新及再次进入保留已提交答案；未提交的复习答案暂不保存。
- 完成任务不会自动标记题目已掌握；用户可以手动标记。再练一次从该题重新作答，不覆盖已经完成的安排记录。
- 待复习安排支持弹窗修改日期或取消。原错题删除后未完成安排提示不可作答，已完成记录依然可查看保存的题目和答案。
- MySQL 使用独立的 review_schedules 表保存安排、版本与结果。重新生成或删除 AI 课程计划不会删除这些安排。
- 日期使用香港时区的自然日，完成时间按 UTC 存储、按香港时区显示。接口校验账户归属、真实日期、重复安排与并发版本，批量添加失败时整体回滚。
- 已验证批量安排、重复及并发添加、账户隔离、改日期、取消与恢复、交卷幂等、保存答案、来源删除历史保留、与课程计划独立。网页验证单选及多选作答、刷新和浏览器前后导航。
- 后端 7 组测试通过，前端构建通过。此条为复习安排交付时的状态；全站搜索随后实现，见第 10 节。

### 错题复习位置与排版优化（2026-10-07）

复习安排从学习计划页移到错题复习页，与错题本通过顶部标签切换。安排成功直接打开安排列表，首页全部安排和答题返回入口均指向这里。刷新保留当前标签。使用蓝白卡片、紧凑状态按钮和统一靠右的操作区，小屏幕自动改为上下布局。已验证首页跳转、刷新恢复、进入复习与返回列表，前端构建通过。

## 9. 实施方案与后续建议

### 全站搜索（第一版已实现，见第 10 节）

- 入口放在右侧内容区顶部，沿用固定左侧导航；结果在页面内展示。
- 搜索课程、章节、资料名称与已提取文字、学习笔记正文、错题题干。首期关键词匹配。
- 结果显示类型、名称、所属课程、命中片段；同一条内容避免重复展示。
- 可切换内容类型，或限定一门课程；点击进入对应内容。
- 返回结果页恢复关键词、类型、课程筛选和结果位置；刷新恢复搜索条件并重新请求本人数据。
- 服务器鉴权并分页；空输入不查全文，快速输入取消或忽略过期请求。删除内容在搜索结果中移除，跳转失效给出提示。
- 图片和公式不保证可被关键词检索；仅有原样预览而无提取文字的资料可按资料名称搜索。
- 验收包含五类内容、跨账户隔离、筛选、分页、跳转、返回及刷新、删除失效和快速输入。

### 学习首页整理（搜索之后的建议，待开发）

按照“继续学习 → 今日计划 → 到期错题复习”组织内容，统一卡片、间距和主按钮，减少重复标题及入口。使用真实保存数据，暂无任务时显示简洁空状态。该项尚未修改页面，布局在开发前再确认。

## 10. 全站搜索实现记录（2026-10-07）

- 内容区顶部提供“搜索学习内容”入口，结果在单独页面展示，保持固定导航。
- 搜索本人课程名称/简介、章节名称/说明、资料名称/已提取文字、非空笔记正文、错题题干；类型和所属课程筛选。
- 关键词最长 100 字，忽略首尾空白；空输入不查询。按字面匹配，百分号、下划线不会当作通配符。
- 显示内容类型、标题、课程与章节归属、最多 180 字命中附近片段。名称命中优先，每页 20 条，提供前后分页。
- 笔记使用保存的可见正文，不搜索富文本结构或图片编码。资料不在查询时重新解析，不保证公式与图片可检索。
- 点击进入对应课程、章节、章节笔记或错题作答；资料进入原文件阅读，不保证定位命中词页码。跳转前检查课程/章节/资料/错题是否仍存在。
- 关键词、类型、课程、分页及结果区滚动位置按账户暂存在当前浏览器会话，返回搜索页重新查询；刷新恢复条件。查询延迟 300 毫秒，取消旧请求并禁止旧结果覆盖。
