# 用户信息与设置功能规划

首次规划：2026-10-12；最后更新：2026-10-16
状态：已实现个人资料、设置及配图管理；设置主界面与账号确认弹窗已按宣纸风格调整。

## 一、功能目标与入口

将用户信息、个人偏好和账号操作集中到头像附近，保持现有学习导航清晰。

- 用户端入口位于顶部导航右侧：头像旁为小齿轮设置按钮；管理端使用自身账号区域入口。
- 点击头像或昵称打开“个人资料”弹窗；点击齿轮打开“设置”弹窗。
- 切换账号、退出账号放在设置底部。
- 窄屏仍能找到这些入口；图标提供文字提示和键盘操作支持。

## 二、个人资料

使用紧凑弹窗展示以下内容：

| 项目     | 行为                                                                               |
| -------- | ---------------------------------------------------------------------------------- |
| 头像     | 支持上传、更换、移除；未设置时显示昵称首字。校验图片格式和大小，失败时保留原头像。 |
| 昵称     | 支持修改；保存后账号区域与个人资料同步更新。拒绝空昵称，并提供长度提示。           |
| 登录账号 | 展示当前账号，首版不提供修改入口。                                                 |
| 邮箱     | 展示绑定状态；更换时验证新邮箱，并验证当前账号身份，校验占用情况。                 |
| 密码     | 单独弹窗填写原密码、新密码和确认密码；使用现有密码规则。                           |

- “取消”和“保存”按钮尺寸一致，位于弹窗右下角。
- 未修改时不显示虚假的保存过程；保存失败保留输入并允许重试。
- 关闭有未保存修改的弹窗时，显示“继续编辑”和“放弃修改”；继续编辑后可使用原设置页的保存按钮。
- 修改密码成功后按现有服务端会话失效规则重新登录，并给出清楚提示。

## 三、设置弹窗

桌面使用纵向纸笺弹窗，上方横向页签、下方设置内容。常规设置外框为 440×580px，切换页签保持尺寸稳定；低视口和窄屏按可用空间收紧，必要时只滚动内容区。

### 外观

- 主题：浅色、深色、跟随系统。
- 界面字号：小、标准、大，作用于菜单、按钮、标签和提示文字。
- 阅读字号：作用于课程文字正文、AI 回答和笔记默认字号。
- 字号调整提供即时预览；取消恢复原设置，保存后持久生效。
- 笔记中已单独指定字号的文字保留原格式；仅调整未指定字号文字和后续输入的默认字号。
- PDF 原页和图片不通过文字字号强行重排，继续使用阅读器缩放。
- 深色模式覆盖用户端页面、弹窗、表单、编辑器和状态提示，保证文字与选中状态清晰。

### 学习偏好

- 默认打开：学习首页或上次页面。
- 是否恢复上次阅读位置。
- 阅读字号统一放在外观中，避免出现两个互相冲突的配置入口。
- “默认打开”作用于重新进入应用；正常刷新继续保持当前页面，浏览器前进后退仍遵循导航历史。
- 上次页面或课程已删除、无权访问时，回到学习首页并给出简短说明。

### 助手设置

- 默认模型：只列出管理端已开放且当前用户可使用的模型。
- 回答长度：简洁、适中、详细。
- 默认模型用于新对话；当前对话中主动选择的模型不被意外替换。
- 模型停用或不可用时提供可用选项与提示，不显示虚假的可用状态。
- 回答偏好用于后续对话请求，不改写已有聊天记录。

## 四、切换账号与退出账号

### 切换账号

1. 检查当前编辑内容，等待可自动保存的内容保存成功。
2. 有尚未提交的表单或保存失败时，让用户选择继续处理或明确放弃，不能直接丢弃。
3. 清除当前登录凭据和当前账号的内存显示状态，进入登录页，提示登录其他账号。
4. 登录新账号后加载其自己的资料、设置和学习数据。

首版不提供多个账号同时登录，也不保存明文密码。后端已提交的生成任务按原账号继续处理，切换后不显示到其他账号中。

### 退出账号

- 与切换账号使用相同的未保存内容检查。
- 清除登录状态，回到登录页，已保存的学习数据保留。
- 浏览器后退不得重新展示退出前的受保护内容；同浏览器其他标签页同步退出状态。
- 按现有登录机制处理服务端会话失效，避免仅隐藏页面却仍保持有效登录。

## 五、保存与数据隔离

- 个人资料与设置按用户保存在服务端，刷新、重新登录后仍然有效。
- 浏览器缓存如需使用，必须按账号隔离，不能把上个账号的偏好或聊天内容带给下个账号。
- 设置加载失败时允许重试，不用临时默认值覆盖已保存设置。
- 接口只能读取和修改当前登录用户的数据；输入与图片在后端校验。
- 不改动管理端系统配置；个人模型偏好不能绕过管理员开放范围。

## 七、完成标准

- 头像和昵称保存后各入口一致，刷新后不丢失。
- 邮箱和密码修改具备身份验证，失败时不会误报成功。
- 界面字号与阅读字号独立调整，已有笔记格式不被覆盖。
- 设置可预览、取消和保存，重新登录后正确恢复。
- 切换账号不串数据，退出后受保护页面不可直接访问。
- 未保存内容不会被静默丢弃；生成中的后台任务归属不变。
- 浅色、深色、跟随系统以及不同字号下，用户端主要页面与弹窗没有遮挡或错位。
