# 访问与启动网站

## 在线访问

- 用户端：<https://shuyoufang.asia/>。
- 管理端：<https://shuyoufang.asia/admin>，使用已创建的管理员账号登录。

直接打开以上地址即可使用，无需在自己的电脑启动项目。关闭网页或云服务器终端页面不会停止网站；服务可用性取决于云服务器和服务进程的运行状态。

## 本地开发启动

以下仅供开发人员在本机运行源码使用。

双击项目根目录的 `start-site.cmd`，等待网站在默认浏览器打开。

- 自动启动尚未运行的前端和后端；已运行时复用，不重复启动。
- 服务在后台运行，关闭浏览器不会停止服务，重启电脑后需要再次双击启动。
- 需要 MySQL 已启动、后端 `.env` 配置正确且项目依赖已安装。
- 出错时窗口会保留提示；项目根目录 `startup-logs` 保存本次启动日志。
- 本地开发入口以启动脚本打开的页面为准，正式使用请访问上方公网地址。

启动脚本优先使用 `D:\node.exe`，找不到时使用系统 PATH 中的 Node.js。启动脚本不会安装依赖、修改密钥或停止占用端口的进程。
