# 数有方管理端完整规划

规划日期：2026-10-09

状态：基础管理、公告管理和扩展筛选已实现；后续功能按第十一节推进。规划项目不代表已经实现。

## 一、定位与已确认事项

用户端继续面向个人自主学习者。管理端负责维护平台、账户、AI 服务和运行情况，属于平台运营后台。

已确认：

- 不需要教师端，不增加教师、班级、布置作业、考试发布和班级排名。
- 管理端与用户学习页面分开，使用独立入口。
- 初始管理员账号为 `admin`，初始密码为 `admin`，用于当前本地开发环境。
- 管理员密码通过初始化程序设置，数据库仅保存 bcrypt 哈希；服务每次启动不能重置密码。
- 普通用户不能访问管理页面，也不能直接调用管理接口。
- 用户已有课程、笔记、练习和学习记录继续按账号隔离。

管理端的核心流程：

登录管理端 → 查看运行概况 → 查找用户或异常任务 → 执行必要处理 → 保留操作记录。

| 用户管理   | 谁在使用，账户是否正常？         | 搜索、筛选、查看账户概况、停用与恢复            | 首版                     |

## 三、页面与布局

独立管理入口暂定为 `/admin`。进入后展示管理端登录或后台页面。

左侧导航：

1. 管理首页
2. 用户管理
3. 课程与资源
4. AI 服务
5. AI 任务
6. 公告管理
7. 系统维护
8. 操作日志

顶部显示当前页面名称、管理员信息、返回学习端和退出登录。

页面规则：

- 使用与当前项目一致的蓝白配色，控制标题、按钮和表格字号。
- 左侧导航固定；右侧页面滚动，不让菜单跟随正文滑走。
- 查询页面统一使用“筛选栏 → 表格 → 分页”的结构。
- 详情使用侧栏或独立详情页；添加、编辑、停用和删除使用网页内弹窗。
- 取消与确认按钮宽高一致，放在弹窗右下角。
- 弹窗适应管理端内容区和小屏幕，不遮住侧栏或超出视口。
- 保存、查询和生成期间显示明确状态，防止重复提交。
- 成功提示短暂显示；失败提示保留处理入口。
- 刷新保持当前页面；浏览器前进、后退与页面层级一致。
- 大列表从后端分页，搜索和筛选条件保留在页面地址中。

## 四、各模块详细规划

### 4.1 管理首页

首版显示：

- 用户总数、正常用户数、停用用户数。
- 课程数、章节数、资料数。
- 原文件与笔记图片的实际占用容量。
- 正在执行、已完成、失败和取消的 AI 生成任务数量。
- 最近异常任务，以及前往对应管理页面的入口。
- 后端、数据库、AI 和邮件服务的配置或连接检查结果。

后续增加近 7 天、近 30 天的注册与使用趋势。

统计规则：

- 全部来自真实数据，不使用模拟数字补满卡片。
- “已配置”和“连接验证通过”分开显示；没有测试过连接不能显示“正常”。
- AI 完成率按指定时间内的已完成与失败任务计算，运行中和取消任务单独统计。
- 后台生成任务、知识问答请求和文件解析分别统计，避免把不同操作混在一起。
- 目前没有记录的活跃、耗时、调用量或费用数据，显示“暂无统计”，补充记录后再展示。

### 4.2 用户管理

列表字段：账号、昵称、角色、邮箱验证状态、账户状态、注册时间、课程数、资料占用。

功能：

- 按账号或昵称搜索，按角色、状态和注册时间筛选。
- 查看用户账户概况和学习数据数量。
- 停用账户，填写处理原因；需要时恢复账户。
- 停用不删除课程、资料和学习记录。
- 停用后阻止新登录，并使现有登录状态无法继续调用受保护接口。
- 保留停用、恢复等操作记录。

边界：

- 后台不显示密码或密码哈希。
- 用户邮箱变更与密码找回沿用邮箱验证流程，不直接修改成“已验证”。
- 首版不开放管理员替用户重置密码，不把密码重置成统一默认值。
- 首版不做永久删除用户；需要注销或清除数据时另行设计确认、备份与恢复流程。
- 当前管理员不能停用自己，不能移除最后一个有效管理员。
- 后续如需增加管理员，单独增加受保护的授权流程，不通过公开注册创建管理员。

### 4.3 课程与资源

建议分为“课程列表”和“资料列表”两个页签。

课程列表：所属账号、课程名称、章节数、资料数、创建时间、更新时间。

资料列表：文件名称、所属课程与账号、文件类型、大小、导入时间、解析状态、预览状态。

功能：

- 搜索、筛选、分页，查看资源与账户之间的关系。
- 识别文件不存在、解析失败、预览失败和记录失效等异常。
- 查看原文件、预览缓存、笔记图片的分类容量。
- 对支持重建的预览执行重新生成，原文件保持完整。
- 清理前先列出候选缓存和预计释放空间，再确认处理。

边界：

- 默认查看元数据，不直接展开用户笔记、聊天正文和资料全文。
- 首版不代替用户修改章节、练习答案、学习笔记或答题记录。
- 预览缓存可重建；上传原件和笔记图片属于学习数据，不能作为缓存批量清理。
- 异常文件必须结合数据库引用关系判断，不能仅按文件创建时间删除。
- 后续如需处理违规内容，单独补充处理权限、原因与用户告知流程。

### 4.4 AI 服务

功能：

- 展示已经接入的服务提供方和真实模型白名单。
- 区分普通问答、章节整理、总结、出题、笔记和计划所使用的模型。
- 展示连接地址、密钥配置状态和最近一次连接检查时间。
- 后续支持设置超时、并发上限、单次题量等参数，后端校验合理范围。
- 后续支持暂停新的 AI 请求；已有任务的取消单独处理。
- 服务异常时显示可理解的原因，例如鉴权失败、限流和连接超时。

配置规则：

- 环境变量提供初始配置；管理端保存后以数据库中的配置为准，密钥加密存储，接口不返回密钥正文。
- API 密钥不返回明文到前端，不进入浏览器存储或日志。
- 后续增加密钥更新功能时采用单向提交，不提供“查看完整密钥”。
- 模型名称和可用状态以服务端实际接入情况为准，不添加无法调用的占位模型。
- 连接测试明确提示会发起一次实际请求，成功结果包含检查时间。
- 修改配置不能覆盖运行中任务使用的参数快照。
- 费用只有在记录了供应商用量与计费依据后才能估算，并标明是估算值。

### 4.5 AI 任务

统一展示以下任务：

- AI 整理章节。
- 章节总结。
- 智能出题。
- AI 生成或整理笔记。
- 学习计划生成。

列表字段：任务编号、任务类型、所属账号、课程与章节、状态、开始时间、结束时间、耗时、失败原因摘要。

功能：

- 按类型、状态、用户和时间筛选。
- 查看任务进度和脱敏错误说明。
- 首版以查询为主；后续接入安全取消和重试。
- 重试创建新任务，并关联原任务，不把原失败记录改成成功。
- 管理员重试沿用原输入与版本保护，不替用户决定采用结果。
- 生成结果仍由学习者预览和确认；后台不能强行覆盖现有笔记或课程结构。
- 课程或章节已删除、输入失效、版本冲突时说明原因，不盲目重试。
- 防止重复点击引发多个相同任务；取消后不能再次写入结果。

“生成完成”和“用户已采用”分开表示。结果完成不等于已经替换学习内容。

知识问答目前需要补充请求指标后才能纳入统一调用统计；不默认收集对话正文。

### 4.6 公告管理

字段：标题、正文、展示位置、状态、发布时间、结束时间。

功能：

- 创建、编辑、预览公告。
- 状态分为草稿、已发布、已下架。
- 指定展示位置，例如学习首页或登录页。
- 已支持设置结束时间，到期停止对用户展示；定时发布仍待开发。
- 下架后用户端不再展示，管理端保留记录。
- 删除前确认，优先采用可恢复的删除方式。

公告使用简洁文本或经过安全处理的富文本，不执行嵌入脚本。

### 4.7 系统维护

#### 基础设置

- 网站名称与基本说明。
- 允许上传的文件类型、单文件大小、文件数量。
- 用户端公告展示开关。
- AI 新请求暂停与恢复。

上传设置必须与实际解析能力一致；限制改变后，对新上传生效，已有资料不直接失效。

#### 服务检查

- 后端和数据库连接状态。
- 邮件与 AI 服务配置状态、测试结果。
- 文件目录是否可读写，是否存在缺失资源。
- 运行错误摘要，不将环境变量、完整密钥或用户正文直接展示为日志。

邮件连接检查与实际邮件送达验证分开记录。

#### 备份与恢复

完整备份范围：MySQL 数据、上传原文件、笔记图片；预览与缓存根据需要保留。

- 首版提供备份范围、存储位置和维护说明。
- 后续增加创建备份、查看进度、备份列表、受保护下载和保留策略。
- 备份包含清单、时间、大小和完整性校验。
- “备份已生成”与“恢复已验证”是不同状态。
- 先在独立环境恢复演练，确认一致性后再支持正式恢复。
- 正式恢复前进入维护状态，保存现状备份并二次确认目标，避免直接覆盖运行数据。
- 环境配置单独受保护保存；密钥不放进普通后台导出包。
- 当前聊天记录和本地草稿位于浏览器，不包含在数据库备份中，页面需要说明这一限制。

#### 缓存与空间

- 展示可重建缓存的大小。
- 清理前预览候选项目，确认后后台执行。
- 清理期间不影响原文件和已保存学习内容。
- 不提供无范围的“一键清空所有数据”。

### 4.8 操作日志

记录：管理员、操作时间、动作、目标类型与编号、结果、处理原因、请求编号。

应记录的操作：

- 管理端登录成功或失败、退出登录。
- 用户停用与恢复。
- 配置更新、连接测试。
- 任务取消与重试。
- 公告发布、修改和下架。
- 备份创建、下载、恢复与缓存清理。

规则：

- 记录必要的变更前后摘要，敏感字段脱敏。
- 不记录密码、密钥、验证码、完整令牌和用户正文。
- 日志由后端写入，不能由前端传入“执行成功”冒充记录。
- 首版支持分页查询和筛选，不开放手动编辑或删除日志。
- 后续增加保留周期、受保护导出和归档。

## 五、账户与权限

首版只设置两个角色：个人学习用户、管理员。

| 操作范围                     | 个人学习用户           | 管理员                     |
| ---------------------------- | ---------------------- | -------------------------- |
| 管理自己的学习内容           | 可以                   | 在自己的学习账号范围内可以 |
| 查看管理端概况和列表         | 不可以                 | 可以                       |
| 停用与恢复普通用户           | 不可以                 | 可以，须确认并记录原因     |
| 查询生成任务状态             | 只能查看自己的任务     | 可以查询平台任务元数据     |
| 修改平台配置或发布公告       | 不可以                 | 功能接入后可以             |
| 浏览其他用户的笔记与聊天正文 | 不可以                 | 首版不提供该能力           |
| 查看密钥或用户密码明文       | 不可以                 | 不可以                     |
| 永久删除用户及全部学习数据   | 不可以通过管理接口操作 | 首版不提供该能力           |

权限必须由后端判断。管理端接口每次检查数据库中的当前角色与账户状态，不能只信前端页面或旧令牌中的角色。

管理登录增加失败次数限制；管理操作使用事务和必要的版本检查，避免多个窗口互相覆盖。

## 六、技术与数据设计

沿用项目现有技术栈：

- 前端：React、Vite，管理端页面独立组织，按需加载。
- 后端：Node.js、Express，管理接口统一放在 `/api/admin/*`。
- 数据库：MySQL。
- 登录：JWT；密码：bcrypt。
- 图表按需要引入，首版以真实统计卡片和表格为主。

已有 `users.role` 可区分 `student` 与 `admin`；账户状态、操作日志与公告表已经接入，其余数据结构按功能逐步增加：

| 数据结构             | 用途                                   | 接入阶段     |
| -------------------- | -------------------------------------- | ------------ |
| 用户状态及停用原因   | 控制登录与接口访问                     | 首版         |
| 管理操作日志         | 追踪管理动作                           | 首版         |
| 非敏感系统设置及版本 | 保存平台配置                           | 配置功能阶段 |
| 公告                 | 保存内容、发布状态及时间               | 公告功能阶段 |
| AI 请求指标          | 统计耗时、用量、模型与结果，不保存正文 | 指标功能阶段 |
| 维护任务与备份清单   | 记录备份、清理进度及结果               | 维护功能阶段 |

已有生成任务表继续保留。管理端通过统一查询层整理章节、笔记和计划任务，不先把所有任务表强行合并。

迁移必须兼容现有学习数据，不能因新增管理端而重新建库或清空原表。

## 七、开发顺序与完成标准

### 阶段 1：管理入口和权限基础

交付：独立登录页、初始化管理员、后端管理员鉴权、账户状态、管理端布局、操作日志基础。

完成标准：`admin` 可以进入管理端；普通用户、伪造角色和失效登录状态均不能调用管理接口；密码不会随重启恢复默认值。

### 阶段 2：管理首页和用户管理

交付：真实统计、用户搜索与分页、账户详情、停用与恢复。

完成标准：停用后旧令牌立即失去访问能力，恢复后可正常登录；用户学习数据保留；操作成功与失败都有明确提示。

### 阶段 3：课程资源和 AI 任务查询

交付：课程与资源元数据、异常资源列表、统一任务状态与错误摘要。

完成标准：查询来自真实数据；任务类型和状态准确；不泄露资料正文或敏感配置；查询不妨碍学习端使用。

### 阶段 4：AI 配置控制和公告

交付：模型与连接状态、生成限制、任务取消与重试、公告预览及发布。

完成标准：设置实际影响后端行为；取消任务不再写结果；重试不覆盖原记录；公告发布与下架在用户端正确生效。

### 阶段 5：维护与完整闭环

交付：备份任务、清理预览、服务检查、日志筛选，逐步加入使用趋势。

完成标准：完成独立环境恢复演练，备份清单与文件一致；清理只处理已确认范围；维护任务可查看进度与失败原因。

## 八、首版范围与后续扩展

首版完成阶段 1 至阶段 3，先让管理端能够登录、看清平台情况、管理账户和定位异常。

阶段 4、阶段 5是完整管理端的后续补齐内容，不在首版页面中放置无法使用的按钮。

按实际需要再考虑：多管理员分工、细分权限、通知投递、定期备份、故障告警、用量配额和数据保留策略。

管理端开发过程中保持用户端现有学习流程可用，不引入教师业务。

## 九、当前实现范围（2026-10-09）

### 11.2 AI 任务：从查询补到处理

任务详情展示任务类型、所属账号、课程和章节名称、状态、可取得的进度、时间、错误摘要，以及允许执行的操作。缺少历史时间或模型记录时显示“未记录”，不能推测补齐。默认不展示输入正文和生成正文。

取消流程：点击取消 → 弹窗填写原因并确认 → 后端检查当前任务状态 → 中止执行或标记取消 → 学习端同步结果。

- 仅允许取消正在生成的任务。保存中的任务按实际状态明确提示，不承诺已经中止。
- 已完成、已失败、已取消的任务不能重复取消。
- 用户自行取消与管理员取消共用状态规则，记录发起方。
- 后端必须阻止被取消任务的迟到结果写入。

重试流程：打开失败任务 → 查看能否重试与原因 → 确认 → 创建关联的新任务 → 查看新任务进度。

- 先支持失败任务重试，不对所有状态开放重试。
- 检查用户是否正常、课程与章节是否存在、原输入是否可用、内容版本是否变化。
- 资料或版本已变化时，提示学习者重新发起生成，不能直接沿用失效输入。
- 防止双击和多窗口重复创建，原任务保留原状态，新任务保存来源任务编号。
- 完成结果交给学习者查看和采用，管理员重试不直接覆盖笔记、章节、计划或练习。
- 操作日志记录管理员、原因、原任务与新任务编号和结果。

### 11.3 课程与资源：异常详情和预览修复

资料详情集中展示文件名称、类型、所属课程与账号、原件状态、预览状态、解析状态和最近处理结果。

- 原件缺失：提示由学习者重新上传，不提供无法执行的重建按钮。
- 原件存在且格式支持：允许重建预览，作为后台任务运行，切换页面后仍可查看进度。
- 新预览成功后再替换旧预览；失败时保留原来可用的版本。
- 同一资料已有重建任务时不能重复发起。
- “暂无文字”不自动认定文件损坏，扫描件、图表和公式资料仍可通过原样阅读使用。
- 修复预览不自动重新生成章节、笔记和习题，不修改用户学习内容。
- 文件访问权限不足、格式不支持、转换程序不可用分别给出可理解的说明。

### 11.4 服务检查与基础设置

服务状态页增加“检查连接”，点击前说明检查范围。AI 检查会产生一次真实请求，可能消耗供应商额度；通过只能代表这次请求成功，不能代表所有任务正常。

- AI：保存服务、模型、检查时间、结果与耗时；错误脱敏，不返回密钥。
- 邮件：先支持配置和连接检查；实际送达需明确填写测试收件地址并单独发起，不能自动给平台用户发信。
- 数据库、文件目录：检查连接和必要读写能力；临时探测文件应清理。
- 页面保留最近检查结果，旧结果显示检查时间，避免长期显示未经复查的“正常”。

基础设置第一批仅包括：单文件上传大小、每次上传数量、暂停新的 AI 生成。允许类型的可配置范围限制在后端已经支持的格式内。问答与后台生成是否一起暂停必须分别定义和显示，不能只关闭前端按钮。

- 保存前校验范围，显示具体字段错误；使用设置版本避免多窗口覆盖。
- 暂停新生成不自动取消正在运行的任务；恢复后允许重新发起。
- 设置保存到后端持久化存储，记录变更前后摘要、时间和管理员。
- 后续再加入模型选择、超时和并发上限；敏感密钥继续由后端环境配置管理。

管理员账户增加“修改密码”：输入当前密码、新密码、确认密码。验证成功后保存哈希，撤销该账号旧登录状态并要求重新登录。当前已初始化的 `admin` 账号不会因部署或重启被恢复成默认密码。

- API 操作日志优先显示对应服务名称，配置删除后显示已删除的 API，不显示内部配置编号。

## 十六、管理员任务处理（2026-10-10）

- 任务列表增加详情，展示账号、课程、状态、进度、可取得的时间和错误摘要，不展开正文。
- 管理员填写原因后可以取消运行中的课程生成、笔记或学习计划任务；保存中和已结束的任务拒绝取消。
- 失败任务可以创建关联重试任务，原失败记录保留；重复重试被持久记录阻止，结果仍交由学习者查看和采用。
- 重试检查账号和课程有效性；课程生成校验资料与章节签名，笔记校验版本及生成资料，计划校验章节签名、计划版本和日期。旧课程生成任务未记录签名时不允许管理员直接重试。
- 管理员原因及新旧任务关联写入操作日志。内容处置、备份及权限设置仍待继续实现。

## 17. 管理员修改密码

管理员可从侧栏打开修改密码弹窗，校验当前密码、确认新密码；新密码为 8—64 位。修改与操作日志在同一事务中保存，登录版本同步递增，所有旧登录失效，要求重新登录。验证次数受限，日志不保存密码。此功能不会自动修改现有 admin 账号密码。

## 18. 课程与资料处置

管理端课程和资料列表提供暂停与恢复弹窗，填写原因并检查版本，事务保存状态及日志。暂停不删除文件或学习记录；课程访问和单份资料访问由后端拒绝，含暂停资料的章节原文和生成暂时拒绝。暂停会取消关联课程正在生成的任务，已进入保存阶段不承诺中止。预览修复后台运行，新 PDF 检查完成并确认资料未变化后替换引用，失败保留旧版本，原文件始终保留。查看修复弹窗可获取上次任务状态。

## 19. 访问限制与生成并发补充

暂停限制统一处理路径大小写与末尾斜杠，查询参数不能绕过章节原文与生成限制。处置对象类型仅接受明确支持的类型。课程与资料处置锁定所属课程以协调并发操作；后台任务调用模型前再次检查任务状态，已取消任务不继续启动；问答返回前再次检查暂停状态。预览提交成功后的缓存清理采用尽力处理，缓存清理失败不能删除已生效的新预览。

## 管理端运行限制与基础备份（2026年10月11日）

- 管理员可配置资料单文件大小（1—100MB）、单次数量（1—20个）及实际模型请求并发数（1—16）；超额模型请求排队，支持取消，异常后释放并发名额。
- AI 问答与 AI 生成各有暂停开关，禁止新任务；已开始的任务继续执行。学习端生成和管理员重试均检查开关。
- 设置保存到 MySQL，使用版本检查防止覆盖，并记录修改原因；重启后保持。
- 数据备份保存数据库、原资料、笔记图片和可用预览，下载为 ZIP；不包含部署环境文件。服务密钥仍为加密状态，部署环境配置需另外保管。
- 备份与恢复验证后台运行，可切换页面；重启中断标记失败。恢复验证新建独立临时数据库，核对数据内容、关联完整性及文件校验，最后清理临时数据库，不覆盖在线数据。
- 原资料或笔记图片缺失、备份期间文件变化、校验失败均不标记成功；不提供在线覆盖恢复按钮。创建、验证使用原因确认弹窗，取消和确认按钮同尺寸。
- 本轮运行限制、基础备份和独立恢复验证已实现；多管理员分级和复杂恢复工作流继续暂缓。
