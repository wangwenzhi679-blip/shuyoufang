# 学习数据概览：功能规划

日期：2026-10-07  
状态：第一版已实现，已完成后端统计、首页整合与浏览器验证。

## 1. 功能目标

在学习首页集中展示课程进度、练习情况、错题情况与近期学习记录，让用户知道当前进展，并能直接进入对应内容。复用现有课程、练习、笔记、阅读和复习数据，使用本人真实记录。

## 2. 首页布局

沿用蓝白风格和固定左侧导航，保持页面紧凑。

1. 顶部：页面标题与现有搜索入口。
2. 数据概览：已学完章节、已交卷次数、客观题正确率、待掌握错题四张小卡片。
3. 继续学习：课程、上次章节、课程进度与继续学习按钮。
4. 今日任务：学习计划与到期错题复习并列，小屏改为上下排列；到期复习显示数量及入口。
5. 各课程进度：紧凑列表展示课程名、完成章节数和进度条，点击打开课程。
6. 近期学习：显示最近阅读、交卷和笔记更新，按时间排序。

整合首页已有的重复卡片和标题，避免同一指标多处大面积展示。课程进度列表首屏展示最近访问的 5 门课程，“全部课程”进入我的课程。近期记录展示最新 10 条。

## 3. 统计口径

| 指标         | 统计方式                                                     | 无数据时                           |
| ------------ | ------------------------------------------------------------ | ---------------------------------- |
| 已学完章节   | 本人当前课程中已主动标记完成的章节数，同时显示当前总章节数   | 显示 0；没有章节时提示添加学习内容 |
| 各课程进度   | 已完成章节数 ÷ 当前章节总数；显示准确数量，百分比取整数      | 无章节显示“尚未添加章节”           |
| 已交卷次数   | 当前保留的正式练习交卷记录数；重复练习再次交卷计为一次       | 显示 0 次                          |
| 客观题正确率 | 所统计交卷记录中，客观题答对总数 ÷ 客观题总数，按题数加权    | 分母为 0 时显示“暂无记录”          |
| 待掌握错题   | 当前错题本中未标记掌握的题目数                               | 显示 0 道                          |
| 到期复习     | 日期为今天或以前、尚未完成且未取消、来源仍可作答的复习安排数 | 显示 0 项                          |

第一版使用当前保留记录的累计数据，不增加时间筛选。今天按 Asia/Hong_Kong 日期计算。

### 练习统计细则

- 未交卷的作答进度不计入次数或正确率。
- 交卷重试产生的同一记录不重复计算；统计以保存记录唯一标识为准。
- 单选、多选、判断等有确定判分结果的客观题参与正确率；主观题的 AI 参考评价不混入。
- 已提交试卷中的未作答客观题按错误计入；无法判分或历史记录缺少判分数据时排除，并说明存在未纳入记录。
- 按交卷当时保存的题目类型和结果统计，不用后续编辑的答案重新判分。
- 开发前核对历史快照是否包含所需字段；缺少信息时不推算、不编造。任何统计口径调整先同步文档。
- 本期错题复习作答不混入正式练习正确率，避免不同流程重复统计。
- 删除记录后按实际保留的数据重新统计；若删除课程或练习会级联移除记录，概览随之变化，不称为永久累计历史。

## 4. 近期学习记录

- 阅读：复用最近访问或阅读位置记录，同一章节只展示最近一次活动，滚动保存不产生一串重复条目。
- 交卷：一份正式交卷记录对应一条，展示课程、练习名、时间和可用成绩。
- 笔记：同一章节只展示最近一次有效保存，不把每次自动保存都列成独立条目；空白或已删除笔记不展示。
- 统一按实际保存时间倒序，时间相同时使用稳定排序。
- 这是近期活动概览，不承诺保存所有历史操作；清楚展示活动类型和所属课程、章节。

## 5. 点击与跳转

- 已学完章节卡片进入我的课程；课程进度项进入对应课程。
- 交卷次数和正确率卡片定位首页的最近练习区域；该区域保留原有答题记录查看入口。第一版不新增完整历史中心。
- 待掌握错题卡片进入错题本的未掌握范围。
- 到期复习入口进入复习安排并展示到期未完成任务；若当前缺少对应筛选，开发时补齐。
- 近期阅读回到章节及已有可恢复位置；近期笔记打开对应章节笔记；交卷记录打开保存的答题情况。
- 内容已删除或权限失效时提示并更新列表，不跳到错误课程。
- 浏览器前进、后退和刷新沿用现有导航恢复机制。

## 6. 数据与异常处理

- 沿用 React、Node.js 与 MySQL。后端鉴权并按账户统计，开发前核对现有表和接口，再确定查询方案。
- 尽量复用已有首页数据接口，减少重复请求；统计不调用 AI。
- 首次进入首页和返回首页时更新；章节标记、交卷、错题掌握、计划操作和笔记更新后使相关数据及时刷新。
- 加载时显示轻量占位，失败显示重试，不把请求失败当成 0。
- 若保留上一次数据，应标注未更新成功；切换账号时清除前一账户缓存。
- 空账户显示简洁引导，不使用模拟数字。百分比不会出现 NaN 或除零。
- 不展示无可靠记录的学习时长、连续打卡天数或知识掌握评分。

## 7. 验收标准

1. 空账户、无章节课程、全部学完和部分完成统计准确。
2. 多份练习按题数加权；未交卷、重试、主观题和旧记录缺字段按规则处理。
3. 错题标记掌握、复习完成/取消、日期跨天后数量正确。
4. 近期记录去重、排序正确，笔记自动保存不刷屏。
5. 所有卡片和记录入口进入正确内容，删除后的入口有有效处理。
6. 刷新、返回首页和账号切换后数据正确，跨账户不能读取他人数据。
7. 请求失败显示重试而非虚假零值；桌面和小屏布局无拥挤或重叠。
8. 文档记录实际测试范围与限制，验证通过后才标为已实现。

## 8. 开发顺序

先核对数据及统计口径，再实现后端查询；随后整理首页卡片与跳转，最后验证数字、状态更新、导航和布局，并更新中文改动记录。

## 9. 第一版实现与验证（2026-10-07）

- 首页四张统计卡、继续学习、今日计划、到期复习、最近五门课程进度和最近十条活动已接入真实 MySQL 数据；保留待完成练习与最近五次交卷入口。
- 首页进入、返回、刷新时加载，每 30 秒后台刷新统计；复习安排按原有 10 秒刷新。加载失败展示重试，不显示伪造的零值。
- 新交卷记录保存全部题目的题型与判分快照，包含未答题；正确率按客观题总数加权，排除简答题。旧记录缺字段或记录不完整时整份排除，并显示说明。
- 阅读活动合并章节访问与阅读位置，同章节取最近时间；笔记每章节一条，交卷按记录 ID 展示。课程被删除后相应统计随级联删除更新。
- 待掌握错题卡进入错题本；到期安排入口启用“只看今天及逾期安排”，可取消筛选查看其余安排。
- 自动测试：overview.test.mjs 已验证加权正确率、旧记录排除、主观题排除、空账户、MySQL 查询、笔记与交卷链接、账户隔离和删除后的统计。实际接口测试另验证后端重新判分、未答题快照、67% 正确率与到期数量。
- 浏览器测试：使用独立测试账户验证刷新后的 1/2 章节进度、67% 正确率、笔记入口、保存答案入口、到期筛选与浏览器返回；测试数据已清理，未修改真实课程。
- 前端生产构建通过；布局加入小屏断点，实际截图为桌面视区，小屏设备尚未逐台验收。

### 当前边界

- 最近练习仅展示五次交卷，不是完整历史中心；统计依照当前保留的记录。
- 网站交卷已增加提交编号去重。旧客户端未携带提交编号时仍按原接口保存，历史重复数据不会自动合并。
- 跨天通过定时刷新更新；后台挂起的标签页恢复后，可刷新页面立即更新。

## 10. 首页优化与交卷重试去重（2026-10-07）

已落实用户确认的六项优化：

1. 删除正文重复的大号“学习首页”标题，保留顶部页面名称和简短说明。
2. 课程进度、近期学习和任务卡按自身内容高度展示，减少被另一侧撑出的空白。
3. 继续学习强调课程、章节与按钮，进度作为较小的辅助信息。
4. 首页只保留“完整计划”入口；“AI 制定计划”仍在学习计划页。
5. 待完成练习与最近练习并列，小屏上下排列；空记录使用简短说明。
6. 新交卷携带 UUID 提交编号；失败时暂存在当前浏览器会话，刷新或重试沿用同一编号，确认成功后清除，下次练习使用新编号。提交编号按账户、练习隔离。

### 后端保障

practice_attempts 新增可空 request_id、request_hash 字段与练习/提交编号唯一索引，不修改已有答题记录。事务内锁定本人练习，同编号相同答案直接返回原 ID、判分和快照；不同答案返回 409，避免覆盖已保存的结果。新编号正常产生新记录。

### 验证

- attempt-requests.test.mjs：实际 MySQL 并发两次提交、连续重试、答案冲突、跨账户访问、再次练习，以及客户端提交编号持久化逻辑通过。
- 实际 HTTP 接口：首次 201、重试 200 且 ID 相同、冲突 409、新一轮 201；首页只统计两轮真实提交，正确率 100%。
- overview.test.mjs 回归通过，前端生产构建通过。
- 桌面浏览器验证首页紧凑布局、刷新保留统计、“完整计划”入口及计划页 AI 制定按钮保留。
- 测试使用独立账户，结束后删除测试数据，不更改用户课程。小屏沿用响应式断点，本轮未逐台实测移动设备。
