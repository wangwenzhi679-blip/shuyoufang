# 图片课本问答、出题与错误提示修复

## 已定位的问题

任务 21、22 在出题之前的 OCR 阶段失败，错误为“识别置信度过低或文字无效”。原实现直接终止，没有读取原页图片的替代路径；管理端还会把含“资料”“文字”等词的不同错误统称为资料识别异常。

## 当前行为

- 已映射到原 PDF 页码的章节，课程助手与智能出题直接将对应原页图片提供给当前账号所选模型，不再先执行 OCR，也不先调用模型转录成文字。
- 助手连续对话、根据回答生成练习、多选题答案核对均保留图片输入。人工修正正文仍优先使用；不包含原图的文字资料继续使用文字路径。
- 图片覆盖所选章节全部映射页，按物理页码排序并去重；不改用别的章节或旧乱码正文。
- 整门课程范围中的纯图片 PDF 可直接发送原页；本次图片总量超过 32 页或 32 MiB 时，明确提示改选较小章节，不静默截断图片。此限制是本应用的请求预算，不是对所有模型能力的保证。
- 只引用当前课程查询所得的 PDF 文件，拒绝不属于当前课程的映射或跨目录文件名。取消信号贯穿读取、识读和出题过程。
- 提示模型直接看图，图片看不清时必须说明，不得猜测。模型已知不支持图片时，在渲染前明确提示打开设置更换模型，不能自动切换模型。
- 原图使用服务端原页缓存，图片字节仅用于本次模型请求，不写入聊天消息或来源记录。
- 管理端区分 OCR、模型图片能力、格式校验、资料版本冲突等错误，不再统一归咎于原文件。
- 生成任务失败、笔记/计划生成错误及统一系统异常提示追加“如仍有问题，请联系管理员”，仍保留具体原因；认证控制所需的登录状态提示保持兼容。

当前路径针对 PDF 原页；不代表新增了上传 JPG/PNG 作为整本教材的入口。图片问答和出题会调用当前模型，服务需要支持图片输入。旧的 OCR 后识读替代函数仍兼容其他调用方，生产环境的上述问答与出题入口优先走原图直传。
