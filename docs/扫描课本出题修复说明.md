# 扫描课本出题与错误提示修复

## 已定位的问题

任务 21、22 在出题之前的 OCR 阶段失败，错误为“识别置信度过低或文字无效”。原实现直接终止，没有读取原页图片的替代路径；管理端还会把含“资料”“文字”等词的不同错误统称为资料识别异常。

## 当前行为

- 正常可提取的文字与人工修正正文继续优先使用。
- 已映射到原 PDF 页码的章节遇到 OCR 质量不合格时，改用当前账号模型逐批识读本章原页图片，再从正文生成练习。
- 每批两页，覆盖全部映射页并去除重复页；不改用整本课本、别的章节或旧乱码正文。
- 只引用当前课程查询所得的 PDF 文件，拒绝不属于当前课程的映射或跨目录文件名。取消信号贯穿读取、识读和出题过程。
- 图片识读不清时停止，并指出原 PDF 页码。模型不支持图片时明确提示，不能自动切换模型。
- 管理端区分 OCR、模型图片能力、格式校验、资料版本冲突等错误，不再统一归咎于原文件。
- 生成任务失败、笔记/计划生成错误及统一系统异常提示追加“如仍有问题，请联系管理员”，仍保留具体原因；认证控制所需的登录状态提示保持兼容。

当前替代路径针对已有章节物理页码映射的扫描 PDF；不代表新增了上传 JPG/PNG 作为整本教材的入口。图片识读会调用当前模型，服务需要支持图片输入。

## 检查范围

通过模拟模型的出题流程、页码范围、拒绝猜测、取消、账号模型隔离、OCR 缓存及安全错误分类检查。没有调用真实付费 AI，尚未在云端对原失败课本完成实际出题验收。
