# 备份与恢复

## 数据放在哪里

| 位置                              | 内容                                                                                       | 是否需要备份                 |
| --------------------------------- | ------------------------------------------------------------------------------------------ | ---------------------------- |
| MySQL 项目数据库                  | 账户、课程、章节、题目、答题记录、错题、笔记正文、学习计划、进度、书签及课程封面与配图记录 | 必须                         |
| `server/storage/course-materials` | 上传的原文件                                                                               | 必须                         |
| `server/storage/note-images`      | 已上传的笔记图片                                                                           | 必须                         |
| `server/storage/course-covers`    | 当前课程封面和已生成候选图片                                                               | 必须                         |
| `server/storage/chapter-images`   | 章节配图和候选图片                                                                         | 必须                         |
| `server/storage/course-previews`  | 文档预览及原页缓存                                                                         | 建议保留，减少重新转换       |
| `server/.env`                     | 数据库连接、AI 等服务配置                                                                  | 单独私下保存，不上传公开仓库 |
| 浏览器网站数据                    | AI 助手对话、本地未同步草稿及待上传图片                                                    | 不包含在数据库和文件备份中   |

资料和预览路径若通过 `.env` 的 `UPLOAD_DIR`、`PREVIEW_DIR` 自定义，应备份实际配置的目录。笔记图片、课程封面与章节配图路径目前固定在后端工作目录下。自动书名排版无需单独图片文件。

## 备份步骤

1. 等待笔记和答题进度显示已保存，处理待上传图片，暂停编辑和 AI 生成。
2. 停止项目的前后端服务，保留 MySQL 运行。关闭浏览器不会停止后台服务；不要把关闭浏览器当成停服。
3. 用 MySQL 管理工具导出项目数据库的结构和数据。数据库名以 `server/.env` 的 `MYSQL_DATABASE` 为准。
4. 将 SQL 文件、上述文件目录和私下保存的配置放到同一份带日期的备份中，记录备份时间。
5. 重要聊天记录先手动复制保存。当前没有完整的聊天和浏览器草稿导出功能；清除网站数据、换浏览器或换设备可能无法恢复这些内容。
6. 在独立测试数据库中验证 SQL 能导入，再检查课程、资料、笔记图片和答题记录。仅成功生成备份文件不等于恢复成功。

## 恢复步骤

1. 保留当前数据的另一份备份，停止项目服务。
2. 优先把 SQL 导入新的测试数据库，避免覆盖现有学习数据。
3. 将同一份备份的原资料、笔记图片、课程封面、章节配图和预览目录恢复到对应位置，保持文件名不变。
4. 将后端配置指向恢复的数据库，核对资料路径，然后启动网站。
5. 逐项检查课程、章节、原文阅读、笔记图片、练习历史、错题和计划。确认无误后再决定是否切换正式使用。

本说明基于代码存储位置核对；尚未进行完整的备份恢复演练。恢复会改动数据库和文件，执行前应明确目标位置。
