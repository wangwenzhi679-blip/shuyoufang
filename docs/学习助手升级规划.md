# 学习助手升级规划

更新日期：2026-10-16
状态：本轮功能已实现。AI 问答及练习生成需配置有效的服务凭证。

## 一、调整方向

保留已经确定的宣纸底色、墨色文字、浅苔绿按钮与少量朱红点缀，沿用左右分栏。页面标题为“学习助手”，引导语为“问有所思，学有所悟。”。

当前左侧“研习方式”和输入框附近的快捷问题都在填入提示词，功能重复。新版让左侧负责学习范围与对话管理，右侧负责提问、理解和成果沉淀。增加实际学习能力，不靠堆放按钮丰富页面。

## 二、页面分工

| 区域           | 内容                                   | 作用                                   |
| -------------- | -------------------------------------- | -------------------------------------- |
| 左侧：研习档案 | 当前课程、章节范围、新建对话、最近对话 | 决定围绕什么学习，并找回不同主题的讨论 |
| 右侧：研习对话 | 消息、资料引用、回答操作、后续问题     | 完成问答并转为笔记或练习               |
| 底部：输入区   | 输入框、模型选择、发送或停止           | 保持主要操作集中，避免重复入口         |

已移除左侧重复的“知识梳理、难点讲解、学习建议”模式按钮。开始新对话时可在右侧空白区显示少量引导问题；对话开始后，改为与当前回答有关的后续问题。

## 三、本轮实现的核心功能

### 1. 章节范围选择

- 左侧先选择课程，再选择“整门课程”或一个具体章节。
- 右侧明确显示当前问答范围，后端检索与回答真正遵守该范围，不能只改界面标签。
- 没有章节时仅提供整门课程；资料不足时说明缺少依据，不编造引用。
- 对话绑定自己的课程及章节范围。切换范围开启新的讨论，已有记录保留，避免混用上下文。
- 课程、章节与资料访问均按当前用户权限校验。

### 2. 独立对话记录

- 同一门课程支持多个主题的对话，例如“第一章难点”和“考前复习”。
- 提供“新建对话”、最近对话列表、重命名和删除。列表展示简短标题及更新时间，长列表按需加载。
- 每个对话分别保存消息、学习范围和输入草稿；切换、刷新后可以接着聊。
- 对话保存到后端并按账号隔离；现有本地记录迁移时去重，成功前保留原记录。
- 删除前确认；删除对话不连带删除已经保存的学习笔记和练习。
- 请求中切换页面或对话时，结果仍归属原对话，不写入新对话。

### 3. 根据回答生成练习

- 在有实际内容的回答下提供“生成练习”，与“加入笔记”并列。
- 依据当前回答及其课程资料生成少量相关题目，可选择题量和难度。
- 先预览，再选择开始练习或保存；不直接把未经查看的题目写入正式题库。
- 接入现有答题、交卷和错题复习流程，避免另建一套孤立练习。
- 新生成或尚未作答不计为学习完成；进度按现有真实完成规则更新。
- 生成失败可重试，防止重复提交产生重复练习。

## 四、配套能力

### 资料引用

回答中的来源可以点击，打开对应资料、章节或可定位的页码，并保留返回对话的路径。只有真实检索到的来源才能展示；原资料删除或定位失效时给出准确提示，不跳转到无关内容。

### 笔记沉淀

保留已有“加入笔记”能力，继续选择目标章节、预览内容后保存。保存状态真实反馈，避免重复点击插入多份；保存后可查看对应笔记。

### 后续问题

根据当前回答给出两到三个简短追问，例如“举个生活例子”“比较这两个概念”。与回答无关时不强行展示。点击先填入输入框，由用户决定是否发送；不在左右两处重复显示同一组入口。

### 对话操作与连续性

- 复制回答、重新生成、失败重试。
- 生成时提供停止操作；停止后保留已收到内容，并标明未完成。
- 重新生成保留原回答，失败不丢失已有内容。
- 离开当前页面后，任务状态可恢复；结果回到原对话，不能只靠前端等待维持。
- 清楚区分生成中、已停止、失败和完成，失败提示不伪装为正常回答。

## 五、界面细节

- 左栏保持紧凑，课程封面只作身份提示，给对话列表留下空间。
- 右栏为主要阅读区域，输入区固定在对话面板底部，不遮挡最后一条消息。
- 回答操作使用细字与轻量图标，不给每个操作都加大色块。
- 正文清晰易读，标题保持与网站一致的书卷感；装饰不能压过内容。
- 手机端将左栏内容收为可展开的范围与历史入口，保证输入框和发送按钮可用。
- 保留键盘操作、可见焦点和 Enter 发送、Shift + Enter 换行；中文输入法选字时不误发送。

## 六、实施顺序

1. 明确课程与章节范围，建立独立对话的数据结构和保存接口。
2. 将左侧改为研习档案，接入范围选择、新建、切换、重命名及删除对话，并迁移旧记录。
3. 增加回答生成练习，接入预览、练习及交卷流程。
4. 完善可点击引用、相关追问、笔记操作及复制、停止、重试、后台结果恢复。
5. 统一桌面和窄屏布局，让页面功能与现有水墨风格协调。

本轮已接入章节范围、独立对话、回答生成练习、资料引用、相关追问及对话操作。旧对话保留并按账号迁移；后台任务支持离开页面后继续，服务重启中断的任务可重新生成。
